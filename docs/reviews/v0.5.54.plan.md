# v0.5.54 — MQTT QoS 1 inflight

## Goal

A subscriber granted QoS 1 gets a packet-id PUBLISH and the
slot frees only after PUBACK. The publisher hot path does not
allocate.

## Performance

Fixed 16 slots, memcpy of topic+payload only. Fanout is
off the CMQ PUBLISH path (MQTT listener thread).

## Security

Bound memory. Do not trust unknown packet ids. Do not block
the publisher on a slow subscriber window.
