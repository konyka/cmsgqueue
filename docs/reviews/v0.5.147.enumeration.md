# v0.5.147 — attach routes on reload

## Scope
Create copies `route=` into live config and `cmq_server_run`
dials each peer (`r0`…`r7`). Reload never copied a fresh
`route=` row and never dialed, so SIGHUP could not enable
cluster peers when create had none. v0.5.143 attaches an
empty pool only.

## Design (performance-first, safety, reliability)

- `cmq_route_reload_attach`: empty addr and port 0 keep
  off. Non-IPv4 / bad port fail closed.
- Dials only when the live slot addr is empty. Existing
  live addr is left alone (no redial).
- Server copies the slot after a successful CONNECT+CONNACK,
  binds an egress reader when the loop is live, and starts
  `route_reconn_thr` if the server is already running.
- Routes without a pool fail closed.
