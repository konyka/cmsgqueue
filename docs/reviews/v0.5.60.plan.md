# v0.5.60 — Transaction coordinator

## Goal

Several publishes sharing a txn id become visible together
on commit, or not at all on abort. A commit record survives
restart so a retry does not apply twice.

## Performance

PUBLISH without headers is unchanged. Persist I/O runs only
on commit/abort when a log directory is set.

## Security

Txn ids must be non-zero. Path traversal on the log dir is
rejected. Uncommitted adds never reach WAL.

## Stop

- Unit tests green (new + idempo).
- Push `v0.5.60` to `origin`.
