# v0.5.141 — attach JWKS refresh on reload

## Scope
Create GETs `jwks_url` and starts the sidecar only when
`jwks_refresh_sec` > 0. Reload updated the interval on a
live sidecar only, so SIGHUP could not enable refresh
when create had a cache but no thread.

## Design (performance-first, safety, reliability)

- `cmq_jwks_refresh_attach`: 0 / omitted / empty URL keeps
  off. Bad URL or interval fails closed.
- Starts only when `*r` is NULL and a cache is live.
  Existing sidecar is left to `cmq_jwks_refresh_reload`.
- Does not GET. First fetch stays create-time.
