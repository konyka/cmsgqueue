# v0.5.87 — Partitioned consume cursors (D4 follow-up)

## Scope
`cmq_stream` has one ack watermark per consumer. This
increment adds 1–16 partitions: keyed append hashes to a
part, and `next_part` / `ack_part` keep isolated cursors.
Default `nparts=1` leaves the append path unchanged.

## Design (performance-first, safety, reliability)

- `set_partitions` only on an empty stream (1–16).
- `append` still part 0. `append_key` stores FNV-1a % n.
- Per-message part in a `max_msgs` sidecar (no store change).
- Cursor file `CMQC2` when n>1; `CMQC1` unchanged.
- Wrong-part ack fails closed. n=0/17 rejected.
