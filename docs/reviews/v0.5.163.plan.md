# v0.5.163 — attach txn coordinator on reload

## Goal

SIGHUP creates the txn coordinator when create left
`txn` NULL. An existing coordinator is not remounted.
Persist attach stays empty / omitted / fail-closed.

## Performance

Existing coordinator: one pointer check, no alloc.
First attach: one `calloc` plus mutex/cond init.

## Security

NULL `**t` fail-closes. Does not remount a live log
or rewrite `persist_dir`.
