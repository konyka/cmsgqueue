# v0.5.119 — reload auth / JWT / nkey

## Scope
CONNECT reads `auth_username`, `auth_password`,
`jwt_issuer`, `jwt_hmac_secret`, `jwt_leeway_sec`,
`nkey_pub`, `jwt_ec_pub`, and `jwt_rsa_n` / `jwt_rsa_e`
from the live `srv->config`. `cmq_server_reload` loaded
those keys into a throwaway `fresh` and freed them, so
secret rotation required a process restart.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_auth` copies non-empty fresh strings
  onto the live config (strdup, then swap).
- Empty or omitted strings keep the current values.
- `jwt_leeway_sec` 0 keeps the current leeway; 1–3600
  replaces it; out of range fails closed with no copies.
- All-or-nothing: a failed strdup rolls back the temps.
- JWKS cache / `jwks_url` refresh stay create-time
  (the live cache is not rebuilt from `jwks_json`).
