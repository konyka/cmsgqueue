# v0.5.90 — JWT HS256 token issuing (D3 follow-up)

## Scope
Verify-only JWT cannot mint a CONNECT password. This
increment adds `cmq_jwt_sign_hs256` so a compact HS256
token is produced from the same secret the server checks.

## Design (performance-first, safety, reliability)

- HS256 only (matches `jwt_hmac_secret`).
- Claims: `iss`, `sub`, `exp` (required). No extra I/O.
- Reject `"`, `\`, controls in iss/sub (same as verify parse).
- Secret cap 128; token cap 2048.
- Sign is off the PUBLISH path.
