# v0.5.113 — config string ownership (tls_ca / ACL / blocklist)

## Scope
`tls_ca`, `acl_allow`, `acl_deny`, and `blocklist_file` were
parsed with `cfg_set_str` and used by the server, but
`cmq_config_free` did not free them and `cmq_server_create`
did not `strdup` them. A load+free leaked; destroy could
alias a caller literal or a load heap that was later freed.

## Design (performance-first, safety, reliability)

- Empty value means disabled (NULL), same as `persist_dir`.
- `cmq_config_free` owns the four strings.
- Create NULLs then `OWN` (strdup) so destroy cannot free a
  caller literal.
