## P1 — Multi-threaded accept loop

- **gap** → `src/server/cmq_server.c:712, 7069` (single listen fd
  registered with the ev_loop; accept_cb runs on the ev_loop
  thread). High connect rates bottleneck.
- **impact**: 100K+ conn/sec can't be served.
- **effort**: L (multi-threaded accept + per-conn handoff).

## P1 — Multi-listener runtime accept loop

- **gap** → `src/server/cmq_server.c:7027` (cmq_server_run binds
  only `listen_fds[0]`; slots[1..3] are reserved but never bound).
- **impact**: cannot serve two distinct certs/ports from one process.
- **effort**: M (200 LOC: iterate slots, per-listener accept_cb).

## P1 — WS permessage-deflate

- **gap** → `src/server/cmq_ws.c` (extend WS handshake to negotiate
  `permessage-deflate; server_no_context_takeover`; per-conn z_stream).
- **impact**: bandwidth waste on WS clients.
- **effort**: L.

## P1 — TLS session_init cache

- **gap** → `src/enterprise/cmq_tls.c` (SSL_CTX_load_verify_locations
  + SSL_CTX_set_alpn_protos called fresh per session).
- **impact**: TLS handshake latency.
- **effort**: M (cache + per-session hook).

## P1 — close-by-fd protection

- **gap** → `src/server/cmq_server.c` (cmq_clients[] indexed by fd;
  close + re-bind race could clobber the new client).
- **impact**: rare race.
- **effort**: S (test + verify race-safe).

## P1 — mqtt_bridge shutdown wired

- **gap** → `src/enterprise/cmq_mqtt_server.c` (cmq_mqtt_bridge_shutdown
  exposed in v0.5.4 but not called from any shutdown path).
- **impact**: in-flight bridge entries leak at process exit.
- **effort**: XS (call from cmq_server_destroy).

## P1 — TLS partial-state cleanup on bad config

- **gap** → `src/enterprise/cmq_tls.c:331` (if cmq_tls_load fails
  mid-way, partial state leaks). v0.5.6 added return-value checks
  on a few APIs but not all early-out paths.
- **impact**: small leak on bad config.
- **effort**: XS (cleanup on each early-out path).

## P2 — cmq_atomic_u64 32-bit portability

- **gap** → `src/core/cmq_atomic.h` (assume _Atomic uint64_t is
  always available; not portable to -m32 if it's not).
- **impact**: potential build failure on 32-bit targets.
- **effort**: XS.

## P2 — 5.0 wildcard PUBACK match

- **gap** → `src/enterprise/cmq_mqtt_server.c` (no `+` wildcard
  match support in PUBLISH delivery).
- **impact**: 5.0 compliance gap.
- **effort**: M.

## P2 — rate-limit log spam

- **gap** → `src/enterprise/cmq_mqtt_server.c` (v0.5.6 set_crl logs
  at most 1/sec, but rate_limit_check has no log).
- **impact**: low.
- **effort**: XS.

## P2 — accept fd leak on shutdown

- **gap** → `src/server/cmq_server.c` (accept_cb doesn't close the
  listen fd on shutdown if the ev_loop is torn down before).
- **impact**: fd leak.
- **effort**: S.

## P3 — mqtt bridge freelist

- **gap** → `src/enterprise/cmq_mqtt_server.c` (g_mqtt_bridge_payloads
  heap-allocated on every publish; no freelist).
- **impact**: malloc churn on high rate.
- **effort**: S.

## P3 — freelist growth cap

- **gap** → `src/server/cmq_server.c` (per-worker msg_freelist
  unbounded; pathological case could grow without limit).
- **impact**: memory leak.
- **effort**: S (add cap + free-on-excess).

## P3 — mqtt listener shutdown log

- **gap** → `src/enterprise/cmq_mqtt_server.c` (mqtt_thread exits
  silently; no INFO log on graceful shutdown).
- **impact**: ops visibility.
- **effort**: XS.

## P3 — TLS regression test

- **gap** → `src/enterprise/cmq_tls.c` (no test for refcounting the
  CTX under UAF regression).
- **impact**: potential UAF on regression.
- **effort**: S (test only).
