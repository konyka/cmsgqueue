# v0.5.91 — JWT ES256 / RS256 issuing

## Goal

Mint compact ES256 and RS256 tokens that the existing
verify functions accept.

## Performance

Sign is off the PUBLISH path. One DigestSign per mint.

## Security

Private key bytes stay with the caller. iss/sub reject
JSON metacharacters. Bad key sizes fail closed.

- Unit tests green (new + existing jwt).
- Push `v0.5.91` to `origin`.
