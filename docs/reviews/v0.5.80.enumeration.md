# v0.5.80 — multi-node 2PC (D5 phase 3)

## Scope
The coordinator commits locally. Clustered PUBLISH must
PREPARE on live routes, collect votes, then COMMIT or
ABORT. This increment adds that 2PC.

## Design (performance-first, safety, reliability)

- No live routes: existing COMMIT path (no wait).
- With live routes: add remote_ids as participants,
  durable-prepare, fan out PREPARE, wait ≤200 ms, then
  COMMIT (all yes) or ABORT (any no / timeout).
- Incoming PREPARE on a route peer: begin+add+prepare
  and VOTE back. No re-fanout (`is_route`).
- COMMIT/ABORT from a route applies locally only.
- 8 participants. Missing `cluster_node_id` cannot VOTE
  (fail closed).
