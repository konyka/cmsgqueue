# v0.5.80 — multi-node 2PC

## Goal

COMMIT with live routes is two-phase: PREPARE + votes
across those peers, then COMMIT or ABORT.

## Performance

No routes: one pointer check, existing apply. Wait and
route I/O run only when the pool has live peers.

## Security

Timeout and missing votes are NO. Route peers do not
re-broadcast PREPARE. Recover still treats only `C`
records as committed.

## Stop

- Unit tests green (new + existing txn).
- Push `v0.5.80` to `origin`.
