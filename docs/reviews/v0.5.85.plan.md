# v0.5.85 — Route write retry

## Goal

An EAGAIN on a live route peer is retried from a
bounded queue instead of being counted as a drop.

## Performance

Copy into a fixed ring. PUBLISH does not wait on the
peer. Drain is a short write pass.

## Security

Cap 32×2048. Dead peers are not retried forever.
Hard write failures still drop the fd.

## Stop

- Unit tests green (new + cluster route).
- Push `v0.5.85` to `origin`.
