# v0.5.150 — load persisted subscriptions on reload

## Goal

SIGHUP restores F18 ghost subscriptions when persist
attach just opened the WAL. An already-loaded handle
is not replayed.

## Performance

One sequential read of `cmq-subs.wal`. A second call
is one integer compare.

## Security

NULL persist cannot invent a load. Missing cb fails
closed. Ghost refs have no client (no live delivery).
