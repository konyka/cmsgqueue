# v0.5.131 — reload jwks_refresh_sec

## Scope
Create starts the JWKS sidecar with `jwks_refresh_sec`.
Reload ignored the interval, so SIGHUP could not slow or
speed a live refresh without a restart.

## Design (performance-first, safety, reliability)

- `cmq_jwks_refresh_reload`: 0 / omitted keeps. 5–86400
  stores the interval on the sidecar (`atomic_uint`).
  1–4 and >86400 fail closed.
- Does not start a sidecar or change `jwks_url`.
- Existing GET / ping-pong path is unchanged.
