# v0.5.155 — apply ACL strings on reload

## Goal

SIGHUP copies non-empty `acl_allow` / `acl_deny` onto
the live config. Empty/omitted keeps the current CSVs.
`..` / `\` fail closed.

## Performance

Same-string compare avoids a heap copy. One `strdup`
per changed CSV.

## Security

`..` / `\` / controls fail closed. A failed copy does
not rewrite either live string.
