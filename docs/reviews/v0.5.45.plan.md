# v0.5.45 — WAL compact / rotate

## Goal

Bound on-disk WAL growth without putting I/O on every publish
when the cap is unset.

## Performance

- Default: one false compare after append.
- `compact(retain)` is operator/startup I/O, not the hot path.
- Rotate stalls one append every `rotate_bytes` (rare).

## Security

- Fail-closed on CRC / I/O during copy (leave live files).
- `.tmp` / `.1` stay under the existing dir+prefix sandbox.
