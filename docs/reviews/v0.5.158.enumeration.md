# v0.5.158 — attach object store on reload

## Scope
Create opens `{persist_dir}/obj` for `$OBJ`.
v0.5.144 only created it inside the filestore-attach
block, so a live filestore whose obj handle was still
NULL never got the object store.

## Design (performance-first, safety, reliability)

- `cmq_obj_reload_attach`: empty/omitted keeps off.
  Existing `*obj` is left alone (no remount).
- `..` / `\` fail closed. Create miss keeps off
  (same best-effort as F18 attach).
- Uses live `persist_dir` (WAL dir). Does not remount
  the filestore or rewrite the live path.
