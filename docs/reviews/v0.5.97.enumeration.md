# v0.5.97 — Per-listener slot 3 `tls_no_tickets` coverage

## Scope

v0.5.96 wired `tls_no_tickets` for listener slots 1-3 and
tested slot 1 enabled with slots 0 and 2 left unchanged. The
final supported listener slot, slot 3, remained untested.

## What v0.5.97 ships

- **`tests/test_tls_e2e_handshake.c::listener_slot_3_no_tickets`**:
  - Configure four TLS listeners with distinct valid
    certificates.
  - Set `listeners[3].tls_no_tickets = 1` and leave slots
    0-2 at the default.
  - Assert slot 3's SSL_CTX contains `SSL_OP_NO_TICKET` while
    an untouched slot remains ticket-enabled.
  - Start all four listeners and complete real handshakes
    through the shared CA bundle.

The test covers the upper boundary of the supported listener
array and prevents an off-by-one error that would leave slot 3
unconfigured while slots 1-2 worked.
