# v0.5.97 — COMPRESSED on MESSAGE (F2 follow-up)

## Scope
PUBLISH inflates. Inbound MESSAGE with the bit is still
`pending_error`, so a compressed delivery from a peer is
disconnected. This increment accepts the bit on MESSAGE,
inflates, and republishes plaintext.

REQUEST stays rejected.

## Design (performance-first, safety, reliability)

- Parser: COMPRESSED on BATCH, PUBLISH, or MESSAGE.
- `handle_message`: inflate once (16 MiB), convert to a
  PUBLISH payload, `handle_publish`. Fanout is plaintext.
- Uncompressed inbound MESSAGE stays `unknown op`.
- Uncompressed PUBLISH/BATCH unchanged.
