# v0.5.95 — Stream consume / ack (D4 follow-up)

## Scope
`$JS.<name>` REQUEST returns last. Pull consume and
ack stay on the library. This increment applies
`$JS.<name>.<consumer>` on REQUEST (next) and PUBLISH
(ack).

## Design (performance-first, safety, reliability)

- `$JS.<name>` unchanged (append / get-last). Extra
  dots stay rejected on that parse.
- `$JS.<name>.<consumer>`: both tokens `[A-Za-z0-9_-]`,
  max 32. Third token fails closed.
- REQUEST: add-consumer, copy next payload with an
  8-byte BE seq prefix. Miss is empty. No watermark
  move.
- PUBLISH: 8-byte BE seq acks. Wrong length / unknown
  stream fails closed. Does not append.
- Non-`$` subjects: one existing byte compare.
