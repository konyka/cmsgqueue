# v0.5.166 — attach OTel ring on reload

## Scope
Create calls `cmq_otel_create` + `cmq_otel_start`.
Reload attached OTLP and only called `set_export` when
the exporter was just opened and `otel` was already
live. A NULL ring then left traces off and never wired
export.

## Design (performance-first, safety, reliability)

- `cmq_otel_reload_attach`: existing ring is left alone
  (no remount). Creates when `*o` is NULL, then starts
  the sidecar if it is not running.
- Create miss fail-closes. Start miss keeps the ring
  (same as create `(void)cmq_otel_start`).
- `set_export` runs whenever both handles exist.
