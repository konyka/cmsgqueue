# v0.5.74 — JWT ES256

## Goal

CONNECT can verify an ES256 JWT against a P-256 public key
from `jwt_ec_pub` or a JWKS EC `kid`.

## Performance

EC verify runs only when `alg` is ES256. HMAC path is
untouched. JWKS still parsed once at create.

## Security

Reject non-P-256 curves, short coordinates, and HS256/ES256
algorithm confusion. Still verify-only.

- Unit tests green (new + jwt + jwks).
- Push `v0.5.74` to `origin`.
