# v0.5.62 — JWT / NKEY verify

## Goal

A CONNECT password that is a compact JWT is accepted only
when HS256, issuer, and expiry match. An Ed25519 public key
can verify a detached nkey signature.

## Performance

JWT path is off accept (worker CONNECT). Default servers
do one NULL compare.

## Security

Verify-only. Tokens are not logged. Clock skew is bounded.
Wrong algorithm fails closed.
