# v0.5.172 — verify CHECKSUM on RESPONSE

## Goal

RESPONSE with `CMQ_FLAG_CHECKSUM` verifies and
strips the trailing CRC32C before inbox decrement
and subject parse. Omitted flag keeps the payload
unchanged.

## Performance

No flag: one bitwise-AND. Flag set: one CRC32C
over the wire payload plus a 4-byte strip.

## Security

Mismatch / short / NULL fail closed before inbox
decrement. Inflate still runs first so
COMPRESSED+CHECKSUM covers plaintext.
