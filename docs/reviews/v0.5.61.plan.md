# v0.5.61 — OTel span ring

## Goal

Publish can enqueue a span without blocking on export. A
full ring drops the newest span.

## Performance

Offer: one atomic increment. Sidecar sleeps on empty.
PUBLISH without otel: one NULL compare.

## Security

Spans carry only trace id, kind, and timestamp. No subject,
no payload.

## Stop

- Unit tests green (new + trace).
- Push `v0.5.61` to `origin`.
