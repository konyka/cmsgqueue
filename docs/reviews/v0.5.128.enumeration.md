# v0.5.128 — omitted log_to_stdout defaults to 1

## Scope
`cmq.h` documents `log_to_stdout` default 1. Load memset
the struct to 0, so a `cmq.conf` that omitted the key
disabled stdout. Create then skipped `cmq_log_add_stdout`.

## Design (performance-first, safety, reliability)

- Load seeds `log_to_stdout = 1` after memset (same pattern
  as `log_level = 2`).
- Explicit `0` or an empty value turns it off.
- `2` still fails closed.
- Programmatic zero-init create is unchanged (0 = off).
