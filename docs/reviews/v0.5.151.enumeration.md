# v0.5.151 — set h2 ALPN on reload

## Scope
Create calls `cmq_tls_set_alpn(..., "h2")` only when both
TLS and `h2_port` exist before `cmq_tls_load`. Reload can
bind `h2_port` after a live SSL_CTX already exists, so
HTTP/2 over TLS had no ALPN.

## Design (performance-first, safety, reliability)

- `cmq_tls_reload_alpn`: empty/omitted keeps off.
  `..` / `\` fail closed.
- Sets ALPN only when `alpn_len` is 0. Existing ALPN is
  left alone (no remount).
- Rebuilds the CTX via `cmq_tls_reload` so the new list
  is on the wire.
