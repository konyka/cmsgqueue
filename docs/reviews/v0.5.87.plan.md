# v0.5.87 — Partitioned consume cursors

## Goal

A consumer can ack one hash partition without advancing
another. Watermarks persist when a cursor dir is set.

## Performance

`nparts=1` (default): append does not touch the sidecar.
Partition scan is O(window) on next_part only.

## Security

Path rules unchanged. Part out of range and wrong-part
ack fail closed.

- Unit tests green (new + existing cursors).
