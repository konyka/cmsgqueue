# v0.5.166 — attach OTel ring on reload

## Goal

SIGHUP creates and starts the span ring when create
left `otel` NULL. An existing ring is not remounted.
Export is wired whenever both handles exist.

## Performance

Existing ring: one pointer check, no alloc.
First attach: one `calloc` plus sidecar thread.

## Security

NULL `**o` fail-closes. Does not rewrite the OTLP URL
or POST.
