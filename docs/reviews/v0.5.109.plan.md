# v0.5.109 — `persist_dir` config-file key

## Goal

Operators can enable persistence from `cmq.conf` without a
programmatic `cmq_config_t` assignment.

## Performance

One extra `strcmp` per config line. Create path gains one
`strdup` when the key is set.

## Security

`..` / `.` components, `\`, and control bytes fail closed.
Empty value disables persist (same as omitted).
