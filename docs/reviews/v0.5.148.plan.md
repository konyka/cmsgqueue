# v0.5.148 — attach TLS on reload

## Goal

SIGHUP loads TLS when create left a slot empty. Existing
SSL_CTX objects are not remounted.

## Performance

One `SSL_CTX` build per empty slot. Existing slot is one
pointer compare.

## Security

`..` / `\` / cert-without-key / missing backend / bad PEM
fail closed. Empty/omitted cannot drop a working CTX.
Plaintext accept stays until a slot is created.

## Stop

- Unit tests green (including PEM apply).
- Push `v0.5.148` to `origin`.
