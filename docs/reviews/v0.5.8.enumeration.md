## P1 — Multi-threaded accept loop

- **gap** → `src/server/cmq_server.c:712, 7069` (single listen fd
  registered with the ev_loop; accept_cb runs on the ev_loop
  thread). High connect rates bottleneck.
- **impact**: 100K+ conn/sec can't be served.
- **effort**: L (multi-threaded accept + per-conn handoff).

## P1 — Multi-listener runtime accept loop

- **gap** → `src/server/cmq_server.c:7027` (cmq_server_run binds
  only `listen_fds[0]`; slots[1..3] are reserved but never bound).
- **impact**: cannot serve two distinct certs/ports from one process.
- **effort**: M (200 LOC: iterate slots, per-listener accept_cb).

## P1 — WS permessage-deflate

- **gap** → `src/server/cmq_ws.c` (extend WS handshake to negotiate
  `permessage-deflate; server_no_context_takeover`; per-conn z_stream).
- **impact**: bandwidth waste on WS clients.
- **effort**: L.

## P1 — TLS regression test (real)

- **gap** → `src/enterprise/cmq_tls.c` (no test for the v0.5.4 UAF
  fix). v0.5.7 shipped a "no-op verification" commit but no real
  ASAN test.
- **impact**: potential UAF on regression.
- **effort**: S (test only).

## P1 — mqtt bridge freelist (payload buffers)

- **gap** → `src/enterprise/cmq_mqtt_server.c` (g_mqtt_bridge_payloads
  heap-allocated on every publish; no freelist).
- **impact**: malloc churn on high rate.
- **effort**: S.

## P1 — 5.0 wildcard PUBACK match

- **gap** → `src/enterprise/cmq_mqtt_server.c` (no `+` wildcard
  match support in PUBLISH delivery).
- **impact**: 5.0 compliance gap.
- **effort**: M.

## P1 — cmq_atomic_u64 32-bit portability

- **gap** → `src/core/cmq_atomic.h` (assume _Atomic uint64_t is
  always available; not portable to -m32 if it's not).
- **impact**: potential build failure on 32-bit targets.
- **effort**: XS.

## P2 — Accept fd leak on shutdown verified

- **gap** → `src/server/cmq_server.c` (v0.5.7 fixed cmq_server_stop
  to close listen_fds; but cmq_server_destroy could double-close).
- **impact**: double-close error on already-closed fds.
- **effort**: XS (guard with -1 check).

## P2 — mqtt bridge cleanup: g_mqtt_sub_topics + g_qos2

- **gap** → `src/enterprise/cmq_mqtt_server.c` (g_mqtt_sub_topics
  + g_qos2 cleared on CONNECT but no free on disconnect). v0.5.4
  P4 did the CONNECT reset; v0.5.8 should add a disconnect clear.
- **impact**: small leak.
- **effort**: S.

## P2 — TLS session cache (real)

- **gap** → `src/enterprise/cmq_tls.c` (v0.5.7 confirmed no per-session
  duplicate work but the ciphers/alpn cache could be even more
  effective with per-session opt).
- **impact**: low.
- **effort**: S.

## P2 — Rate-limit log spam

- **gap** → `src/enterprise/cmq_mqtt_server.c` (rate_limit_check
  doesn't log; if a publisher hits the limit continuously, no

- **impact**: ops visibility.
- **effort**: XS.

## P2 — freelist overflow path

- **gap** → `src/server/cmq_server.c` (the freelist cap drops

- **impact**: bounded.
- **effort**: S.
