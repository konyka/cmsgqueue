# v0.5.79 — HTTPS JWKS

## Goal

`jwks_url` may be `https://host[:port][/path]`. Server
create GETs the JWKS document over TLS with peer verify.

## Performance

HTTP URLs skip TLS. Handshake + GET run once at create,
not per CONNECT.

## Security

Verify-peer required. Optional `jwks_ca` PEM; otherwise
system CAs. No userinfo. 200 ms / 4 KiB caps.

- Unit tests green (new + existing JWKS fetch).
- Push `v0.5.79` to `origin`.
