# v0.5.162 — attach route pool on reload

## Scope
Create calls `cmq_route_pool_create` when a cluster
exists. Reload only did that inside the cluster-attach
block, so a live cluster whose pool was still NULL
fail-closed on `route=` (`fresh.route_count > 0 &&
!server->routes`).

## Design (performance-first, safety, reliability)

- `cmq_route_pool_reload_attach`: no cluster keeps off.
  An existing pool is left alone (no remount / redial).
- First attach: `cmq_route_pool_create` plus optional
  dial gate. Create miss fail-closes.
- Peer dial stays `cmq_route_reload_attach` (empty
  slots only).
