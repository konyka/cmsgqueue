# v0.5.164 — attach KV manager on reload

## Scope
Create calls `cmq_kvb_create` always. Reload only called
`cmq_kvb_reload_attach_persist`, which fail-closes when
`kvb` is NULL and `persist_dir` is set. A live filestore
whose manager was never allocated then blocked every
SIGHUP.

## Design (performance-first, safety, reliability)

- `cmq_kvb_reload_attach`: existing manager is left
  alone (no remount). Creates when `*b` is NULL.
- Create miss fail-closes. Persist attach stays 160.
- In-memory `$KV` works without a WAL.
