# v0.5.113 — config string ownership

## Goal

`tls_ca` / `acl_allow` / `acl_deny` / `blocklist_file` have
the same ownership as `persist_dir`: load owns, create
strdup's, destroy frees.

## Performance

Four extra `strdup`s at create when the keys are set.
Hot path unchanged.

## Security

Empty values disable. Reload frees the prior heap before
memset so a second load cannot leak.

- Push `v0.5.113` to `origin`.
