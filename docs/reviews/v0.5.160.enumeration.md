# v0.5.160 — attach KV persist on reload

## Scope
Create calls `cmq_kvb_set_persist` when `persist_dir` is
set. v0.5.144 only did that inside the filestore-attach
block, so a live filestore whose KV persist dir was still
unset never wrote `{persist_dir}/kv_<bucket>`.

## Design (performance-first, safety, reliability)

- `cmq_kvb_reload_attach_persist`: empty/omitted keeps
  off. An existing persist dir is left alone (no remount).
- `..` / `\` fail closed. Uses live `persist_dir`
  (WAL dir). Does not remount the message WAL.
