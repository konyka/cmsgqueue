# v0.5.160 — attach KV persist on reload

## Goal

SIGHUP enables `{persist_dir}/kv_<bucket>` when create
left KV persist unset. Empty / omitted keeps off. An
existing persist dir is not remounted. `..` / `\` fail
closed.

## Performance

Existing persist: one pointer check, no fopen.
First attach: one path copy. Bucket WAL opens on the
first `$KV` publish (replay last-wins).

## Security

`..` / `\` / controls fail closed. Does not rewrite
live `persist_dir`.
