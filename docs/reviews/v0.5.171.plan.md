# v0.5.171 — verify CHECKSUM on REQUEST

## Goal

REQUEST with `CMQ_FLAG_CHECKSUM` verifies and
strips the trailing CRC32C before subject parse.
Omitted flag keeps the payload unchanged.

## Performance

No flag: one bitwise-AND. Flag set: one CRC32C
over the wire payload plus a 4-byte strip.

## Security

Mismatch / short / NULL fail closed. Failed
verify does not rewrite `*len`. Inflate still
runs first so COMPRESSED+CHECKSUM covers
plaintext (same as PUBLISH).
