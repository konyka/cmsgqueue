# v0.5.136 — reload MQTT bridge addr/port

## Goal

SIGHUP applies `mqtt_bridge_addr` / `mqtt_bridge_port` to
a live outbound bridge. Same-endpoint is a no-op.

## Performance

Same-endpoint: one alive probe. New endpoint: one
CONNECT + CONNACK (existing 2 s dial budget).

## Security

Non-IPv4 and out-of-range port fail closed. Empty/omitted
cannot wipe a working broker.
