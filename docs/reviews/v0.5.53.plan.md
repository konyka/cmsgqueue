# v0.5.53 — Key compaction on sealed segments

## Goal

Operators can shrink a rotated WAL archive by key without
touching the live append path.

## Performance

PUBLISH / `cmq_filestore_append`: no new loads. Compact is
operator I/O on `.1` only.

## Security

Reject oversize keys and oversize archives. Verify CRC before
keeping a record. Atomic rename so a crash cannot mix old/new
`.1` bytes.

## Stop

- Unit tests green (new + existing compact/rotate).
- Push `v0.5.53` to `origin`.
