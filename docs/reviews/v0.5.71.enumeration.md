# v0.5.71 — HPACK Huffman (D2 phase 3)

## Scope
`cmq_hpack_str_decode` rejects the Huffman bit. Real h2
HEADERS almost always set it. This increment adds RFC 7541
Huffman encode/decode and accepts H=1 on string decode.

The 4 KiB dynamic table and an h2 listener stay deferred.

## Design (performance-first, safety, reliability)

- Encode is a 256-entry code/length lookup.
- Decode walks bits; leftover padding must be EOS ones.
- Complete EOS as padding is a decoding error.
- Output cap `CMQ_HPACK_STR_MAX`. No heap.
- Literal (H=0) encode path is unchanged.
