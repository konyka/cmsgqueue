# v0.5.71 — three listeners defensive test

## Scope

Sanity test: a TLS server with three listeners (slot 0, 1, 2)
each with its own cert/key. Verifies all three listeners
accept handshakes independently. The v0.5.52 `multi_listener`
test covered 2 listeners; this extends to 3 to catch any
implicit assumption that "only 2 listeners are supported".

## Test: `tls_e2e_handshake.three_listeners`

1. Generate three different certs (`cert0`, `cert1`, `cert2`).
2. Configure `cmq_server` with `listener_count=3`, each
   listener pointing at a different cert/key.
3. Connect to port `base+0`, `base+1`, `base+2`.
4. Assert all three handshakes succeed.

## What v0.5.71 ships

Just the test. No production change.
