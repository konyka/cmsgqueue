# v0.5.173 — verify CHECKSUM on BATCH

## Scope
PUBLISH / REQUEST / RESPONSE consume
`CMQ_FLAG_CHECKSUM`. The parser accepts the bit
on BATCH; the trailer made `offset != payload_len`
so a correct CRC still failed as invalid batch.

## Design (performance-first, safety, reliability)

- Reuse `cmq_checksum_consume`. 0 / omitted / empty
  flags keep `*len`. Mismatch fail closed.
- `handle_batch` consumes after zstd decompress,
  before count parse, so Pass 1's exact-length
  check sees the stripped payload.
- Re-check `payload_len >= 2` after consume to
  avoid a count overread on a 4-byte trailer.
