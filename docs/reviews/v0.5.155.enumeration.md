# v0.5.155 — apply ACL strings on reload

## Scope
`cmq_reload_apply_dynamic` rebuilds `acl_h` from
`acl_allow` / `acl_deny` but never copied those CSVs
onto `server->config`. Destroy / a later apply still
saw the create-time strings.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_acl_live`: empty/omitted keeps the
  current strings. Same string is a no-op.
- `..` / `\` / controls / len ≥ 512 fail closed (same
  rules as TLS live paths). All-or-nothing.
- Applied after the handle rebuild. Does not remount
  `acl_h`.
