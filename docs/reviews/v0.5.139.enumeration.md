# v0.5.139 — attach OTLP exporter on reload

## Scope
Create parses `otlp_endpoint` and hooks the export sidecar.
v0.5.138 updates a live URL only, so SIGHUP could not
enable export when create had none.

## Design (performance-first, safety, reliability)

- `cmq_otlp_reload_attach`: empty/omitted keeps off.
  Bad URL fails closed.
- Allocates only when `*url` is NULL. An existing exporter
  is left to `cmq_otlp_reload_url`.
- Server hooks `cmq_otlp_export` after a new attach.
  Does not POST.
