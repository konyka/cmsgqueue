# v0.5.79 — HTTPS JWKS (D3 phase 8)

## Scope
`jwks_url` is HTTP-only. IdPs publish JWKS on HTTPS.
This increment accepts `https://` and GETs the same 4 KiB
document over TLS 1.2+.

Refresh stays deferred.

## Design (performance-first, safety, reliability)

- No URL: JWKS cache stays unset (existing path).
- `http://` GET is unchanged (no TLS handshake).
- `https://` verifies the peer. `jwks_ca` is an optional
  PEM; otherwise the system store is used.
- Default HTTPS port is 443. 200 ms I/O; 4 KiB body.
- Userinfo, `..`, and mixed `jwks_json` stay rejected.
