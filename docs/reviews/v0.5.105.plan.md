# v0.5.105 — `$JS` hash partitions

## Goal

`$JS` streams can use 1–16 payload-hash partitions.
Reopen restores `n` and part isolation.

## Performance

`n=1`: one extra partitions compare on PUBLISH.
`n>1`: same `append_key` cost as the stream library.

## Security

Names stay `[A-Za-z0-9_-]`. `n` is 1–16. Set after
the first append fails closed.
