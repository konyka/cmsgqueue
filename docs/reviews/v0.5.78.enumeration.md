# v0.5.78 — OTLP HTTPS (D1 phase 3)

## Scope
OTLP export is HTTP/JSON only. Collectors commonly sit
behind TLS. This increment accepts `https://` endpoints
and POSTs the same JSON over TLS 1.2+.

gRPC OTLP stays deferred.

## Design (performance-first, safety, reliability)

- No endpoint: export hook stays NULL (existing path).
- `http://` POST is unchanged (no TLS handshake).
- `https://` verifies the peer. `otlp_ca` is an optional
  PEM; otherwise the system store is used.
- 200 ms I/O cap. Failures are ignored (ring never waits).
- Userinfo, `..`, and non-https/http schemes stay rejected.
