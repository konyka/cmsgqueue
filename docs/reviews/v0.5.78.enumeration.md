# v0.5.78 — docs-only (test framework stability checkpoint)

## Scope

v0.5.78 ships docs-only. After 34 rounds of defensive testing,
the test suite `tests/test_tls_e2e_handshake.c` has reached
a stable state with 28 defensive tests. v0.5.78 captures a
fresh bench snapshot for the post-v0.5.77 state and
documents the deferred scope for future rounds.

## What v0.5.78 ships

- `docs/reviews/v0.5.78.enumeration.md` (this file).
- `docs/benchmarks/v0.5.78_{1,2}.txt` (bench transcripts).
- `CHANGELOG.md` entry.

## Deferred (unchanged from v0.5.77)

- TLS 1.3 mTLS via post-handshake auth (v0.5.48/v0.5.49 race).
- Per-listener `accept_thread_func` refactor (already on remote
  workstream as v0.5.42).
- Concurrent graceful-shutdown test (framework timing issue).
- Invalid CA bundle rejection test (OpenSSL state issue).
- TLS 1.3 session ticket resumption test (server doesn't issue tickets).
