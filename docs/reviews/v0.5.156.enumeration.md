# v0.5.156 — apply MQTT maps on reload

## Scope
`cmq_mqtt_reload_maps` updates the live bridge from
`fresh`, but `server->config.mqtt_bridge_maps` stayed
at create-time values. Destroy / a later attach still
saw the create-time table.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_mqtt_maps_live`: count 0 / omitted
  keeps the current table. Same table is a no-op.
- Empty subject/topic, qos outside 0–2, `..` / `\` /
  controls / `,` fail closed. All-or-nothing.
- Applied after a successful `cmq_mqtt_reload_maps`.
  Does not remount the bridge.
