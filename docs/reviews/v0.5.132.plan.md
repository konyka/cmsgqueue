# v0.5.132 — empty host is NULL / IPv4 only

A `cmq.conf` that omits or empties `host` binds
`0.0.0.0`. `localhost` fails closed at load.

## Performance

One `inet_pton` at load. No hot-path change.

## Security

Non-IPv4 hosts cannot reach create. Empty cannot
disable the default bind by storing `""`.
