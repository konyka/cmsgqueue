# v0.5.165 — attach $JS manager on reload

## Scope
Create calls `cmq_js_create` always. Reload only called
`cmq_js_reload_attach_persist`, which fail-closes when
`js` is NULL and `persist_dir` is set. A live filestore
whose manager was never allocated then blocked every
SIGHUP.

## Design (performance-first, safety, reliability)

- `cmq_js_reload_attach`: existing manager is left
  alone (no remount). Creates when `*j` is NULL.
- Create miss fail-closes. Persist attach stays 161.
- In-memory `$JS` works without a last/msgs dir.
