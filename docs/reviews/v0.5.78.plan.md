# v0.5.78 — OTLP HTTPS

## Goal

`otlp_endpoint` may be `https://host[:port][/path]`. The
sidecar POSTs OTLP/JSON over TLS with peer verify.

## Performance

HTTP endpoints skip TLS. Handshake + POST run only on the
sidecar, never on `offer`.

## Security

Verify-peer required. Optional `otlp_ca` PEM; otherwise
system CAs. No userinfo. 200 ms I/O cap.
