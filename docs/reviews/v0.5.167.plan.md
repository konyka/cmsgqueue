# v0.5.167 — attach idempo window on reload

## Goal

SIGHUP creates the pid/seq window when create left
`idempo` NULL. An existing window is not remounted.

## Performance

Existing window: one pointer check, no alloc.
First attach: one `calloc` plus mutex init.

## Security

NULL `**t` fail-closes. Does not rewrite persist or
clear a live window.
