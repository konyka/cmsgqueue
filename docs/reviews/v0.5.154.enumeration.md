# v0.5.154 — apply blocklist path on reload

## Scope
Create loads `blocklist_file` into `blocklist_h`. Reload
attached when create had none (v0.5.149) but an existing
handle still used a best-effort `load` + rch swap: `..` /
`\` were accepted, and live `blocklist_file` stayed at
the create path.

## Design (performance-first, safety, reliability)

- `cmq_blocklist_reload_swap`: empty/omitted keeps the
  current list. Same path still re-reads the file.
- `..` / `\` / missing file fail closed (same as attach).
- Copies the path onto live config after a successful
  load. Caller wraps and rch-swaps (no remount of the
  in-flight handle).
