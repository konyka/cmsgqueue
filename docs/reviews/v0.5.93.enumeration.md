# v0.5.93 — Stream PUBLISH path (D4 follow-up)

## Scope
`cmq_stream` is a library. The server process never
appends. This increment adds named streams and applies
`$JS.<name>` on the PUBLISH path (same class as
`$KV` / `$OBJ`).

REQUEST-get / consume stay deferred.

## Design (performance-first, safety, reliability)

- Non-`$` subjects: one existing byte compare.
- `$JS.` then a single name token (`[A-Za-z0-9_-]`, max 32).
- Empty / NULL payload fails closed (ring refuses len 0).
- At most 8 lazy streams. Fanout still runs.
- Optional cursors under `{persist_dir}/js`.
- Bad `$JS.` subjects fail closed (do not store).
