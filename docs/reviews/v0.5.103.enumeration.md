# v0.5.103 — Durable `$JS` last payload (D4 follow-up)

## Scope
Cursors persist under `{persist_dir}/js/{name}.cursors`.
Message bodies die with the ring, so REQUEST-get misses
after reopen. This increment persists the last payload.

## Design (performance-first, safety, reliability)

- Opt-in: only when `cmq_js_set_persist` has a dir.
- After a successful `$JS.<name>` append, write
  `{dir}/js/{name}.last` (`CMQL` + seq + len + body).
- tmp + fsync + rename. Overwrite unlinks the dest first.
- REQUEST-get prefers the last cache; reopen lazy-loads
  the file. Missing file is a miss (does not create a
  slot).
- Earlier bodies stay on the ring. Consume history is
  still not durable.
- Ack PUBLISH does not rewrite `.last`.
