# v0.5.175 — wire INFO host from live config

## Goal

The live INFO frame advertises the bind host.
Omitted / empty host is `"0.0.0.0"`. Non-IPv4
fail closed (no INFO) rather than a lying
default.

## Performance

One `inet_pton` + quote per CONNECT. No
per-message path.

## Security

Only dotted IPv4 is emitted. Quote, backslash,
and control bytes stay rejected.
