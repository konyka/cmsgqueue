# v0.5.72 — HPACK 4 KiB dynamic table

## Goal

HPACK incremental literals populate a 4 KiB dynamic table
so later indexed fields resolve without re-sending names.

## Performance

No heap. Insert/evict compact a 4 KiB buffer. Slot cap 128.

## Security

Oversize table updates, index 0, and a miss on an empty
table fail closed. String caps stay `CMQ_HPACK_STR_MAX`.
