# v0.5.153 — apply TLS paths on reload

## Goal

SIGHUP copies new TLS cert/key/CA paths onto the live
config and rejects `..` / `\` before touching a slot.
Existing SSL_CTX is not remounted except via the
existing `cmq_tls_reload`.

## Performance

Same-string compare avoids a heap copy. One `strdup`
per changed path.

## Security

`..` / `\` / controls fail closed on both live copy
and slot apply. A failed apply does not rewrite live
strings (all-or-nothing dups).
