# v0.5.44 — Trace ID in cmq_log

## Goal

Operators can grep one hex ID and see every log line for that
connection. IDs must actually be generated (fix the inverted
CONNECT assign).

## Performance

- Accept: one RAND_bytes + 32-nibble encode.
- Per frame: two TLS pointer stores. No hex on the PUBLISH path.
- Log write: extra `if (tls)` only when a line is emitted.

## Security

- TLS setter accepts only 32 `[0-9a-f]` chars.
- Trace stays off the wire.
