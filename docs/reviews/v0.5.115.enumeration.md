# v0.5.115 — extra-listener bind host/port

## Scope
`listener_count` and slot TLS are reachable from `cmq.conf`
(v0.5.114), but extra binds still used hardcoded
`127.0.0.1:port+li`. An operator who set `listener_count=2`
could not choose the extra listen address.

## Design (performance-first, safety, reliability)

- `listener{1,2,3}_host` must be IPv4; empty → NULL
  (bind fallback `127.0.0.1`).
- `listener{1,2,3}_port` 0–65535; 0 → `port+index`.
- Slot 0 stays `host` / `port`.
- Create `OWN`s host so destroy cannot free a caller
  literal. Test-port guards unchanged.
