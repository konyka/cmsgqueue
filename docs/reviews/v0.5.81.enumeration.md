# v0.5.81 — ALPN h2 + h2_port (D2 phase 6)

## Scope
The HTTP/2 listener is prior-knowledge only. The server
never advertises `h2` and has no `h2_port`. This increment
binds that port and calls `cmq_tls_set_alpn("h2")` before
TLS load when the port is set.

## Design (performance-first, safety, reliability)

- `h2_port` 0: no listen, no ALPN (existing path).
- `h2_port` > 0: loopback `cmq_h2_listen`. Bind fail = create fail.
- TLS + `h2_port`: `set_alpn("h2")` before `cmq_tls_load`
  so `tls_build_ssl_ctx` installs the protocol list.
- Prior-knowledge POST on the h2 fd is unchanged.
- Non-loopback bind stays rejected.
