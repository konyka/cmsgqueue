# v0.5.116 — reload log_level and acl_deny

## Goal

SIGHUP / `cmq_server_reload` applies the documented log
level and the same ACL deny list create already installs.

## Performance

Reload is off the PUBLISH path. One ACL rebuild + one
`cmq_log_set_level` per successful reload.

## Security

Deny-list is applied on reload. `_probe_` mismatch refuses
to flip default-deny. `log_level` outside 0–5 fails closed.
