# v0.5.162 — attach route pool on reload

## Goal

SIGHUP creates the empty route pool when create left
`routes` NULL. No cluster keeps off. An existing pool
is not remounted. Peer redial stays create-time.

## Performance

Existing pool: one pointer check, no alloc.
First attach: one `calloc` of the pool plus mutex
init. No CONNECT until `cmq_route_reload_attach`.

## Security

NULL `**pool` fail-closes. Does not redial live
peers or rewrite cluster identity.
