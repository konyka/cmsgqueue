# v0.5.134 — reload jwks_ca

## Scope
Create copies `jwks_ca` onto the JWKS URL before the
sidecar starts. Reload ignored the path, so SIGHUP could
not point HTTPS verify at a new PEM.

## Design (performance-first, safety, reliability)

- `cmq_jwks_refresh_reload_ca`: empty/omitted keeps.
  `cmq_jwks_set_ca` rules (`..`, length) fail closed.
- Sidecar snapshots `url` under a mutex so a reload
  cannot tear the CA string mid-GET.
- Does not re-GET `jwks_url`.
