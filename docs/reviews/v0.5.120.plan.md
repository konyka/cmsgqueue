# v0.5.120 — reload JWKS cache

## Goal

SIGHUP / `cmq_server_reload` rotates the static JWKS
document without restarting the process.

## Performance

Off the PUBLISH path. One parse (≤8 keys, 4 KiB) and one
ping-pong `cache_put` per reload.

## Security

Bad JSON keeps the previous slot. Empty/omitted does not
wipe a working cache. CONNECT still copies key bytes out
of the live slot.

- Unit tests green (new + jwks).
- Push `v0.5.120` to `origin`.
