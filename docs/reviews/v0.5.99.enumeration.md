# v0.5.99 — COMPRESSED on RESPONSE (F2 follow-up)

## Scope
REQUEST inflates. RESPONSE with the bit is still
`pending_error`. This increment accepts the bit and
inflates before subject parse / inbox decrement.

SUBSCRIBE and other control ops stay rejected.

## Design (performance-first, safety, reliability)

- Parser: COMPRESSED on BATCH, PUBLISH, MESSAGE,
  REQUEST, RESPONSE.
- `handle_response` inflates once (16 MiB), clears the
  flag, recurses. Inbox decrement runs on the plaintext
  path only.
- Uncompressed RESPONSE: one flag-bit compare.
