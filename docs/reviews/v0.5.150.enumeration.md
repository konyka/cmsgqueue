# v0.5.150 — load persisted subscriptions on reload

## Scope
Create opens `cmq-subs.wal` and
`cmq_sublist_persist_load`s ghost refs into the
sublist. v0.5.144 attached the file on SIGHUP but
never loaded records, so a newly enabled persist_dir
could not restore subscriptions.

## Design (performance-first, safety, reliability)

- `cmq_sublist_persist_reload_load`: NULL persist keeps
  off. Loads once when `*loaded` is 0.
- A second call leaves the sublist alone (no remount).
- Missing cb on a first load fails closed.
- WAL *message* replay stays create-time. This path
  only restores F18 ghost SUB records (client=NULL).
