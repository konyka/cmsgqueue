# v0.5.61 — tls_enabled without cert defensive test

## Scope

A misconfigured `tls_enabled=1` without `tls_cert`/`tls_key`
is a common production mistake. The `cmq_server_create` code
checks for missing cert/key and returns `CMQ_ERR_INVALID_ARG`.

## Test: `tls_e2e_handshake.tls_enabled_without_cert_rejected`

1. Configure `cmq_server` with `tls_enabled=1` and no
   `tls_cert` or `tls_key`.
2. Assert `cmq_server_create` returns non-OK.
3. Assert the server pointer is NULL.

## What v0.5.61 ships

Just the test. No production change.
