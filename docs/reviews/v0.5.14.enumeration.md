## Verdict

v0.5.14 must focus on:
- **Performance**: #3 multi-threaded accept (bench could double)
- **Functional**: #2 multi-listener (with port-guard), #4 WS deflate, #5 5.0 wildcard
- **Reliability**: #7 TLS regression test (real)

The key insight from v0.5.13: change test_server's ports (18801-18803
→ 28801-28803) BEFORE attempting multi-listener bind. The
multi-listener runtime then picks ports 18800-18999 safely.
