# v0.5.114 — listener TLS config keys

## Scope
`listeners[1..3]` and `listener_count` are used at create
(per-slot TLS, extra binds on `port+li`), but `cmq.conf` had
no `listener*` keys. After `srv->config = src`, listener
strings aliased the caller. `cmq_config_free` did not free
them.

## Design (performance-first, safety, reliability)

- `listener_count` 0–4 (0/1 = single listener).
- `listener{1,2,3}_tls_cert|key|ca` (empty → NULL) and
  `listener{1,2,3}_tls_verify_peer` 0–1.
- Slot 0 stays `tls_cert` / `tls_key` / `tls_ca`.
- Free all `listeners[0..3]` strings. Create NULLs then
  `OWN` so destroy cannot free a caller literal.
