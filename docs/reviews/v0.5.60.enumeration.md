# v0.5.60 — Transaction coordinator (D5 phase 2)

## Scope
D5 phase 1 drops duplicate pid+seq. A coordinator that can
buffer several publishes and commit or abort them together
is still missing. D4's log exists (filestore / cursor dir).

This increment adds `cmq_txn`: begin / add / commit / abort
with an opt-in durable commit log. `CMQT` headers are
consumed before WAL/fanout so the default PUBLISH path is
unchanged.

Object-store server wiring and 2PC across nodes stay deferred.

## Design (performance-first, safety, reliability)

- No `CMQ_FLAG_HEADERS`: zero extra work.
- Headers without `CMQT`: one 4-byte compare (after CMQI).
- 32 in-flight txns, 8 ops each, payload cap 1024.
- Commit: fsync the COMMIT record, then apply. Crash before
  the record = abort. Duplicate commit is a no-op.
- Recover loads committed ids only (no re-fanout).
