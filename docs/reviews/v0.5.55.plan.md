# v0.5.55 — Idempotent publish window

## Goal

A publisher can attach `CMQI`+pid+seq so a retry does not
fan out or persist twice.

## Performance

PUBLISH without headers: unchanged. With headers but no
magic: one 4-byte compare.

## Security

Do not admit a new pid when the table is full (would drop
EOS). Duplicates never skip export ACL.
