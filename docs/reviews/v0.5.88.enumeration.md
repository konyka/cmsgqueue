# v0.5.88 — Tombstone TTL + dirty-ratio compact (D6 follow-up)

## Scope
`compact_keys` always drops a last-is-tombstone and is
explicit. This increment adds a segment-age TTL and a
dirty-ratio auto-trigger after rotate / `maybe`.

## Design (performance-first, safety, reliability)

- Default TTL 0 and dirty den 0: same as v0.5.53.
- TTL uses sealed `.1` mtime vs now (no header change).
- Dirty: compact when `drop * den >= total * num`.
- Live append unchanged except one compare after rotate.
- `key_dirty` is read-only (no rewrite).
