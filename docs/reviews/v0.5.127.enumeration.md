# v0.5.127 — reload log sinks

## Scope
Create calls `cmq_log_add_stdout` / `cmq_log_add_file` from
`log_to_stdout`, `log_to_file`, and `log_file`. Reload
applied `log_level` but never the sinks. Calling `add_file`
again would stack a second FILE*.

## Design (performance-first, safety, reliability)

- `cmq_log_reload_sinks` is idempotent. stdout_on=1 adds
  stdout only if missing. file_on=1 with a path replaces
  the file appender; the same path is a no-op.
- 0 / omitted / empty path keeps the current sinks.
- The old FILE* is closed only after other in_flight
  writers finish (snapshot-safe).
- fopen failure fails closed; the previous file stays.
