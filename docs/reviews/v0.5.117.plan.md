# v0.5.117 — reload TLS cert/key

## Goal

`cmq_server_reload` rebuilds each live listener SSL_CTX
from the current (or freshly configured) cert/key paths.

## Performance

Off the PUBLISH path. One `cmq_tls_reload` per live slot
(at most 4) per reload.

## Security

Bad cert/key leaves the previous CTX. Empty paths do not
wipe a working slot.

## Stop

- Unit tests green (new + rld).
- Push `v0.5.117` to `origin`.
