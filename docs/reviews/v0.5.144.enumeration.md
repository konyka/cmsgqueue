# v0.5.144 — attach persist_dir on reload

## Scope
Create opens the WAL and persist sidecars from
`persist_dir`. Reload logged a new path and updated
audit / sync only, so SIGHUP could not enable durability
when create had none.

## Design (performance-first, safety, reliability)

- `cmq_filestore_reload_attach`: empty/omitted keeps off.
  `dir_safe` / create fail closed.
- Opens prefix `cmq` only when `*fs` is NULL. Existing WAL
  is left alone (no remount).
- Server then wires sublist / txn / kv / `$JS` / obj.
  WAL replay stays create-time (would re-PUBLISH into live
  subscribers).
