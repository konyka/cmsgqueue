## 4. Per-P-item Micro-Plans

### P1 F19b full bridge
- **Goal**: `src/enterprise/cmq_mqtt_server.c:441` — relay thread calls `cmq_sublist_insert` for each (topic, payload).
- **Pre**: v0.5.3 plumbing shipped.
- **Implementation**: per-relay, allocate `cmq_sub_ref_t` with synthetic `cmq_client_t`; insert via `srv->sublist` (need server_t* access). ~150 LOC.
- **RED**: `tests/test_mqtt_bridge.c::publish_forwards_to_cmq_subscriber` — start cmq server + bridge, MQTT PUBLISH, assert cmq client receives MESSAGE.
- **Atomic**: `feat(P1): F19b bridge relay inserts into cmq sublist`.

### P1 cmq_tls_reload UAF
- **Goal**: `src/enterprise/cmq_tls.c:302` — defer `SSL_CTX_free` until last SSL* drops.
- **Implementation**: refcount the SSL_CTX, attach to each cmq_tls_session, free when refcount==0; mimic v0.5.1 P1 `cmq_rch` pattern. ~80 LOC.
- **RED**: `tests/test_tls_api.c::reload_during_session_no_uaf` — start session, call reload mid-handshake, assert no ASAN error.
- **Atomic**: `fix(P1): defer SSL_CTX_free until last SSL* drops`.

### P2 MQTT relay clean shutdown
- **Goal**: `src/enterprise/cmq_mqtt_server.c:436` — add `cmq_mqtt_bridge_shutdown()` that signals dying + joins.
- **Implementation**: ~30 LOC.
- **RED**: `tests/test_mqtt_bridge.c::shutdown_drains_queue` — enqueue 10, signal shutdown, assert all consumed.
- **Atomic**: `feat(P2): MQTT relay clean shutdown`.

### P2 Async WAL ring payload bound
- **Goal**: `src/enterprise/cmq_mqtt_server.c:572` — heap-allocate payloads > 1024.
- **Implementation**: change `g_mqtt_bridge_payloads[256][1024]` to `g_mqtt_bridge_payloads[256]` (pointer); malloc on enqueue, free on drain.
- **RED**: `tests/test_mqtt_bridge.c::large_payload_accepted`.
- **Atomic**: `feat(P2): heap-allocate large mqtt bridge payloads`.

### P1 multi-listener runtime
- **Goal**: `src/server/cmq_server.c:7014-7040` — accept loop iterates `tls_config_slots[]`; each slot binds its own fd.
- **Implementation**: ~200 LOC: array of listen_fds, per-listener accept_cb, plumb each new conn to the correct slot's TLS config.
- **RED**: `tests/test_p5_listener.c::two_listeners_distinct_ctx` — start server with 2 listener configs, both accept a TLS handshake with their own cert.
- **Atomic**: `feat(P1): multi-listener accept loop`.

### P1 5.0 property decode
- **Goal**: `src/enterprise/cmq_mqtt_server.c:381` — decode 5.0 properties for PUBLISH/SUBSCRIBE.

### P2 QG dedup 2-level hash

## 6. Risk Register

| Item | Risk | Mitigation |
|---|---|---|
| F19b sublist_insert | Race with cmq's main thread | rdlock on sublist during match; synthetic client_t outlives mqtt thread |
| TLS reload UAF | Hidden in-flight SSL* | refcount the CTX; defer free until last drop |
| 5.0 props decode | Malformed length bytes | bounded var-byte reader; reject on overflow |
| Multi-listener bind | Two ports conflict | explicit error if user-requested port can't be bound |
| QG dedup 2-level | Wrong granularity | identical result vs v0.5.3 dedup in the limit; assert in test |
