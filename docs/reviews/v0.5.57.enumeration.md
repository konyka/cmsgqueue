# v0.5.57 — missing CA bundle path defensive test

## Scope

The v0.5.46 mTLS pipeline calls `SSL_CTX_load_verify_locations`
with the configured `tls_ca` path. If the CA bundle file is
missing, OpenSSL has no trust anchors. With
`SSL_VERIFY_PEER | SSL_VERIFY_FAIL_IF_NO_PEER_CERT`, every
client cert must fail verification. This test verifies the
failure mode is fail-closed (reject all clients) not
fail-open (accept all).

## Test: `tls_e2e_handshake.mtls_missing_ca_bundle`

1. Generate a CA + server cert + client cert.
2. Configure `cmq_server` with `tls_ca=/tmp/cmq-test-no-such-ca.pem`
   (nonexistent path) + `tls_verify_peer=1`.
3. Connect with a valid client cert signed by the (separately
   loaded) CA.
4. Assert the handshake fails.

The test observed OpenSSL error "no such file" — the missing
CA bundle is correctly detected.
