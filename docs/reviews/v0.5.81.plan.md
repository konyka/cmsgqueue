# v0.5.81 — ALPN h2 + h2_port

## Goal

A configured `h2_port` binds the loopback HTTP/2 listener
and TLS slots advertise `h2` via ALPN.

## Performance

`h2_port` 0: no listen fd, no ALPN bytes on the CTX.
Accept stays off the PUBLISH path.

## Security

Loopback-only bind. Create fails if the port cannot bind.
ALPN is set before load (not after).
