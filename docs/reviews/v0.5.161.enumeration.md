# v0.5.161 — attach $JS persist on reload

## Scope
Create calls `cmq_js_set_persist` when `persist_dir` is
set. v0.5.144 only did that inside the filestore-attach
block, so a live filestore whose `$JS` persist dir was
still unset never wrote `{persist_dir}/js/{name}.*`.

## Design (performance-first, safety, reliability)

- `cmq_js_reload_attach_persist`: empty/omitted keeps
  off. An existing persist dir is left alone (no remount).
- `..` / `\` fail closed. Uses live `persist_dir`
  (WAL dir). Does not remount the message WAL.
