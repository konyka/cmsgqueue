# v0.5.138 — reload otlp_endpoint

## Scope
Create parses `otlp_endpoint` onto the exporter URL.
Reload updated CA only, so SIGHUP could not point the
next POST at a new host.

## Design (performance-first, safety, reliability)

- `cmq_otlp_reload_url`: empty/omitted keeps.
  `cmq_otlp_parse_url` rules fail closed.
- Copies host/path/port/tls/grpc onto a live exporter.
  Existing CA is preserved.
- Does not POST. Exporter start stays create-time.
