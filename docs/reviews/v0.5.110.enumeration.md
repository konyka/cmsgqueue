# v0.5.110 — `persist_sync_interval_ms` config-file key

## Scope
`cmq_config_t.persist_sync_interval_ms` was only settable from
C. The parser ignored the key, so a conf-only operator could
not enable periodic WAL fsync (`cmq_filestore_set_sync_interval`).

## Design (performance-first, safety, reliability)

- Parse 0–86400000 (same cap as `ping_interval_ms`).
- 0 = off (default). Server already applies n>0 at create.
- Validate rejects values above the cap.
