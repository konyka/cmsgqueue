# v0.5.143 — attach cluster on reload

## Scope
Create builds `cmq_cluster` + route pool from
`cluster_name` / `cluster_node_id`. Reload ignored those
keys, so SIGHUP could not enable cluster identity when
create had none.

## Design (performance-first, safety, reliability)

- `cmq_cluster_reload_attach`: empty/omitted keeps off.
  Oversize name/id fail closed (`cmq_cluster_create`).
- Creates only when `*c` is NULL. Existing cluster is
  left alone (no remount).
- Server allocates an empty route pool after attach.
  Configured `route=` peers stay create-time (redial).
