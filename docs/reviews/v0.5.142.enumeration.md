# v0.5.142 — attach MQTT bridge on reload

## Scope
Create dials `mqtt_bridge_addr`:`mqtt_bridge_port`.
v0.5.136 updates a live bridge only, so SIGHUP could not
enable the outbound broker when create had none.

## Design (performance-first, safety, reliability)

- `cmq_mqtt_reload_attach`: empty/omitted keeps off.
  Non-IPv4 / bad port fail closed.
- Creates `"cmsgbridge"` and calls
  `cmq_mqtt_bridge_connect` only when `*br` is NULL.
  Existing bridge is left to `cmq_mqtt_reload_endpoint`.
- Failed dial destroys the half-built bridge.
