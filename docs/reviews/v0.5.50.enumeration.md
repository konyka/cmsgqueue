# v0.5.50 — F14 connect-rate on CONNECT

## Scope
`cmq_quota_check_connect` is implemented and unit-tested, but
CONNECT never calls it (`v0.5.1.security.md` §8). This increment
wires the existing per-second window.

Full remaining catalog: `docs/reviews/remaining-unimplemented.md`.
D1–D6 stay deferred.

## Design (performance-first, safety, reliability)

- `srv->quota == NULL` → one pointer compare, no hash.
- `max_connects == 0` → library returns 1 before `find_or_claim`.
- Check **after** account bind, **before** `inc_connections` so a
  rate-limit reject does not consume a concurrent slot.
- Cluster route-adopt is not a client CONNECT; skip.
- Reject: CONNACK 1, audit `rate_limit_reject` / `connect quota`.
