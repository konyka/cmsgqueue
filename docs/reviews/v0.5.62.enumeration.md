# v0.5.62 — JWT / NKEY verify (D3 phase 1)

## Scope
CONNECT is username/password or scrypt hash only. There is
no JWT or Ed25519 verify in `src/`.

This increment adds verify-only HS256 JWT and raw Ed25519
nkey checks using the existing OpenSSL dependency. CONNECT
treats the password field as a JWT when `jwt_hmac_secret`
is set. Verify runs on the CONNECT worker, not accept.

Issuing tokens stays out of tree. JWKS fetch stays deferred.

## Design (performance-first, safety, reliability)

- No secret configured: one pointer check (existing auth).
- HS256 via OpenSSL HMAC. Reject wrong `alg`, `iss`,
  expired `exp`, future `nbf` (60s leeway).
- CONNECT password cap is 2048 only in JWT mode; the 256
  cap remains when JWT is off.
- NKEY: `cmq_nkey_verify` is Ed25519 over a caller buffer
  (no second crypto lib). Seed/base32 codec stays deferred.
