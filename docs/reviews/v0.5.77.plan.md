# v0.5.77 — JWT RS256

## Goal

CONNECT can verify an RS256 JWT against an RSA public key
from `jwt_rsa_n`/`jwt_rsa_e` or a JWKS RSA `kid`.

## Performance

RSA verify runs only when `alg` is RS256. HMAC / ES256
paths are untouched. JWKS still parsed once at create.

## Security

Reject short moduli, algorithm confusion, and RSA keys
that only have `k`. Still verify-only.

## Stop

- Unit tests green (new + jwt + jwks + es256).
- Push `v0.5.77` to `origin`.
