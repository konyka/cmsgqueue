# v0.5.59 — Object store

## Goal

`cmq_obj_put` / `get` / `del` store a named blob that
survives process restart.

## Performance

One open/read or write+fsync+rename per call. No table scan.

## Security

Directory and object names are single path components. A
failed write leaves the previous file.
