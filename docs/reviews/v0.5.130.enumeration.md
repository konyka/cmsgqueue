# v0.5.130 — reload $JS partitions / rotate

## Scope
Create wires `js_partitions` and `js_msgs_rotate_bytes` onto
`cmq_js`. Reload ignored both, so a SIGHUP file could not
change the default for new streams or the history cap.

## Design (performance-first, safety, reliability)

- `cmq_js_reload`: 0 / omitted keeps. parts 1–16; rotate
  1–1 GiB. Out of range fails closed.
- Existing streams keep their `.parts` file (same as create).
- Live config ints update only when the setter succeeds.
