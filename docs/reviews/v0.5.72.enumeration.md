# v0.5.72 — HPACK 4 KiB dynamic table (D2 phase 4)

## Scope
Huffman and the static table are live. Real h2 HEADERS
reuse names via the RFC 7541 dynamic table. This increment
adds a 4 KiB table plus incremental / indexed / size-update
decode.

A dedicated h2 listener and ALPN `h2` stay deferred.

## Design (performance-first, safety, reliability)

- Fixed 4 KiB store + 128 slots. No heap.
- RFC size is name+value+32. Evict oldest until the new
  entry fits; an entry larger than max is not added.
- Size updates and `set_max` reject above 4096.
- Existing static `hdr_decode` / H=0 encode unchanged.
- Indexed static fields do not enter the table.
