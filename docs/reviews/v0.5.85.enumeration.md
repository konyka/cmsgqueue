# v0.5.85 — Route write retry (D5 phase 4)

## Scope
`cmq_route_broadcast` treats EAGAIN as a drop
(`stat_messages_dropped`, no queue). This increment
enqueues those frames and drains them when the peer
is writable.

## Design (performance-first, safety, reliability)

- 32 slots × 2048 bytes. Newest drop when full.
- Queue only `write_full` EAGAIN (`wr==1`). Hard
  disconnects and vanished peers stay misses.
- Drain after broadcast and on the reconnect sidecar.
- Offer copies off the io_lock (retry_lock only).
- Oversize frames are not queued.
