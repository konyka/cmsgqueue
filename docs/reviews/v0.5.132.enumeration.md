# v0.5.132 — empty host is NULL / IPv4 only

## Scope
`cmq.h` says bind host defaults to `0.0.0.0`. Load stored an
empty `host =` as `""`, so create skipped the default and
`inet_pton` failed. Extra-listener hosts already reject
non-IPv4; the main `host` key did not.

## Design (performance-first, safety, reliability)

- Empty `host` stores NULL (create uses `CMQ_DEFAULT_HOST`).
- Non-empty must be IPv4 (`inet_pton`), same as
  `listener{1,2,3}_host`.
