# v0.5.52 — Account outstanding-byte cap

## Goal

Operators can cap concurrent in-flight publish bytes per
account. Default remains unlimited.

## Performance

Unlimited: one cached compare on PUBLISH. No extra get() /
CAS when `account_max_bytes_live` is 0.

## Security

CAS so two publishes cannot both sneak past the cap.
Soft-delete undo prefers leak over theft.
