# v0.5.176 — wire INFO server_id from cluster_node_id

## Goal

The live INFO frame advertises `cluster_node_id`.
Omitted / empty stays `"cmsgsrv"`. Oversize or
unsafe tokens fail closed.

## Performance

One length check + quote per CONNECT. No
per-message path.

## Security

Quote, backslash, controls, and ids at or over
16 bytes are rejected so INFO cannot inject or
truncate-collide.
