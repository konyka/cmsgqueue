# v0.5.123 — reload payload / sub / client caps

## Scope
PUBLISH checks `max_payload_size`, SUBSCRIBE checks
`max_subs_per_client`, and accept CAS-checks `max_clients`
on the live `srv->config`. Reload loaded those keys into
`fresh` and freed them.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_caps` copies non-zero fresh caps.
- 0 / omitted keeps the current cap (create already filled
  payload/subs defaults).
- Values above the parse ceilings fail closed.
