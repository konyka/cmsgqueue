# v0.5.76 — remote JWKS fetch (D3 phase 6)

## Scope
JWKS is a static `jwks_json` blob. IdPs publish
`/.well-known/jwks.json`. This increment GETs `jwks_url`
(`http://host[:port][/path]`) once at server create and
fills the existing 8-key cache.

HTTPS JWKS, RSA, and periodic refresh stay deferred.

## Design (performance-first, safety, reliability)

- No URL: existing JSON / HMAC / EC paths unchanged.
- `http://` only; no userinfo; path rejects `..` / CR/LF.
- 200 ms I/O. Body cap 4 KiB. Non-2xx fails closed.
- `jwks_url` and `jwks_json` are mutually exclusive.
- Fetch is not on the CONNECT hot path (cache only).
