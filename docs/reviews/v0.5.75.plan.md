# v0.5.75 — nkey seed / base32

## Goal

`nkey_pub` accepts a NATS `U…` public key. Seeds decode to
a raw Ed25519 seed so tests can derive the matching public.

## Performance

Hex path is a length check. Base32 runs only when the first
char is not a hex digit length-64 string.

## Security

CRC and prefix are checked before any key is used. Seeds
are not persisted by the server.

- Push `v0.5.75` to `origin`.
