# v0.5.112 — MQTT bridge outbound PUBLISH

## Goal

A mapped CMQ PUBLISH is written as an MQTT PUBLISH on
the connected outbound bridge.

## Performance

No mapping: one lock + linear scan (≤64). Miss returns
without encode. Unconfigured bridge is a NULL check.

## Security

Maps reject `/` in the CMQ subject and `,` / controls.
Inbound MQTT accounts are not re-bridged.
