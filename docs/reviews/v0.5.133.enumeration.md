# v0.5.133 — empty log_file / slot-0 TLS store NULL

## Scope
v0.5.109 said empty `log_file` is disabled (NULL). Load
still stored `""`, so create called `cmq_log_add_file("")`.
Slot-0 `tls_cert` / `tls_key` had the same `""` store;
extra-listener TLS and `tls_ca` already used empty → NULL.

## Design (performance-first, safety, reliability)

- Empty `log_file` stores NULL. Non-empty uses
  `persist_dir_ok` (`..` / `\` / controls fail closed).
- Slot-0 `tls_cert` / `tls_key` use `cfg_set_str_empty`.
- Other non-auth strings (JWT / JWKS / OTLP / cluster)
  also store NULL when empty. Auth username/password stay
  `""` so validate still rejects a zero-credential bypass.
