# v0.5.118 — SIGHUP / config_file

## Scope
N2 documents a SIGHUP handler that re-reads the config
file. `cmq_server_reload` exists (v0.5.116–117) but the
process never installed `SIGHUP`, and `config_file` was
unused so reload had no default path.

## Design (performance-first, safety, reliability)

- `config_file` in `cmq.conf` (empty → disable). Omitted
  key stores the load path. `..` / `\` / controls fail
  closed (same as `persist_dir`).
- Create `OWN`s the path. `cmq_sighup_note` is
  async-signal-safe; `take` is from the event-loop
  post-tick, which calls `cmq_server_reload`.
- Empty `config_file` installs no reload path.
