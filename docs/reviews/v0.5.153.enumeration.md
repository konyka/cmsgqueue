# v0.5.153 — apply TLS paths on reload

## Scope
`cmq_reload_apply_tls` updated live SSL_CTX slots from
`tls_*` / `listener*_tls_*` but did not copy those paths
onto `server->config`, and did not reject `..` / `\`.
Attach already fail-closed and OWN-copied; apply did not.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_tls_live`: empty/omitted keeps the
  current strings. Same string is a no-op.
- `..` / `\` / controls / len ≥ 512 fail closed (same
  rules as attach / `persist_dir`). All-or-nothing.
- `apply_tls` validates paths before any `set_*`.
- String apply only; existing CTX is not remounted
  beyond the existing `cmq_tls_reload`.
