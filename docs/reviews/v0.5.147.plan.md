# v0.5.147 — attach routes on reload

## Goal

SIGHUP dials `route=` peers when create left the live
table empty. Existing live peers are not redialed.

## Performance

One CONNECT+CONNACK per empty slot. Existing slot is one
string compare.

## Security

Non-IPv4 and out-of-range port fail closed. Empty/omitted
cannot drop a working peer. Routes without a pool fail
closed.

## Stop

- Unit tests green (including loopback apply).
- Push `v0.5.147` to `origin`.
