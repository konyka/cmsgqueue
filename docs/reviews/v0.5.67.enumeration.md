# v0.5.67 — empty tls_cert file defensive test

## Scope

Defensive test: `tls_cert` pointing at an empty (zero-byte)
file must fail at server startup, not crash. The
`SSL_CTX_use_certificate_chain_file` call returns 0 on empty
or malformed files; `cmq_server_create` propagates the
failure.

## Test: `tls_e2e_handshake.empty_cert_file_rejected`

1. Create a zero-byte cert file.
2. Configure `cmq_server` with `tls_cert=<empty file>`.
3. Assert `cmq_server_create` returns non-OK.
4. Assert the server pointer is NULL.

## What v0.5.67 ships

Just the test. No production change.
