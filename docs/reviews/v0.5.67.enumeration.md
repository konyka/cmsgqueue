# v0.5.67 — KV bucket PUBLISH path (D4 phase 4)

## Scope
`cmq_kv` is a library. PUBLISH still ignores `$KV.*`.
This increment adds named buckets and applies
`$KV.<bucket>.<key>` on the server PUBLISH path.

Object-store subjects and REQUEST-get stay deferred.

## Design (performance-first, safety, reliability)

- Non-`$` subjects: one byte compare, then the existing path.
- `$KV.` then parse bucket (no dots) and key (dots allowed).
- Empty payload deletes. Non-empty puts.
- At most 8 lazy buckets. Fanout still runs (watchers).
- Optional persist under `{persist_dir}/kv_<bucket>`.
- Bad `$KV.` subjects fail closed (do not store).
