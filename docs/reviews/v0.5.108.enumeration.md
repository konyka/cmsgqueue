# v0.5.108 — `$JS` history WAL rotate (D4 follow-up)

## Scope
`{persist_dir}/js/{name}.msgs` was append-only. The ring
holds 1024 messages, but the WAL grew without bound.
This increment caps the file after append when
`js_msgs_rotate_bytes` / `cmq_js_set_msgs_rotate_bytes`
is set.

## Design (performance-first, safety, reliability)

- 0 = off (default). Hot path is one integer compare.
- When `.msgs` size >= cap, rewrite a contiguous tail
  that fits cap, at most 1024 records (the ring).
- One record larger than cap is still kept.
- tmp + fsync + unlink + rename. Failed compact leaves
  the live file; publish still succeeds.
- Config `js_msgs_rotate_bytes` 0–1 GiB, wired at create.
