# v0.5.104 — Durable `$JS` history WAL (D4 follow-up)

## Scope
v0.5.103 persists the last payload so REQUEST-get
survives reopen. Earlier bodies die with the ring, so
pull consume misses. This increment appends every
`$JS.<name>` body to a history WAL and replays it.

## Design (performance-first, safety, reliability)

- Opt-in: only when `cmq_js_set_persist` has a dir.
- After a successful append, write one `CMQM` record
  (seq + len + body) to `{dir}/js/{name}.msgs`.
- Append + fsync. Replay only onto an empty ring.
- Consume / ack lazy-open the slot when the WAL exists.
- Missing WAL is a miss (does not create a slot).
- `.last` and `.cursors` are unchanged.
- Ring max still 1024; a longer WAL evicts the prefix
  on replay the same as live.
