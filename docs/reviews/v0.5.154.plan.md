# v0.5.154 — apply blocklist path on reload

## Goal

SIGHUP reloads an existing blocklist from a new path,
copies that path onto the live config, and rejects
`..` / `\` / a missing file. An in-flight handle is
swapped, not remounted under readers.

## Performance

One file read + rch swap. Same-string compare avoids
a heap copy of the path.

## Security

`..` / `\` / missing file fail closed. A failed swap
does not rewrite the live path.
