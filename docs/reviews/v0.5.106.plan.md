# v0.5.106 — `$JS` consume-part subject

## Goal

REQUEST `$JS.<name>.<consumer>.<part>` returns the next
message on that hash partition.

## Performance

Two-token consume: one extra parse_cons-success path
(no parse_part). Three-token: one extra parse after
parse_cons fails.

## Security

Part is 0–15 decimal digits only. Names stay
`[A-Za-z0-9_-]`.
