# v0.5.168 — attach log on reload

## Scope
Create calls `cmq_log_create` and does not fail if the
handle is NULL. Reload then called
`cmq_log_reload_sinks`, which fail-closes on NULL and
aborted the whole SIGHUP.

## Design (performance-first, safety, reliability)

- `cmq_log_reload_attach`: existing log is left alone
  (no remount). Creates when `*log` is NULL.
- `level` must be 0–5. Create miss fail-closes.
- Server clamps an out-of-range live `log_level` to
  INFO before attach (same as create).
- Wire before `apply_dynamic` / `reload_sinks`.
