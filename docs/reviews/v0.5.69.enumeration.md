# v0.5.69 — client role confusion defensive test

## Scope

Defensive test against a protocol role-confusion attack: a
malicious client sends a ServerHello (handshake message type
0x02) to a server expecting a ClientHello (message type
0x00). OpenSSL's state machine must detect the role mismatch
and reject the connection.

## Test: `tls_e2e_handshake.client_role_confusion`

1. Spin up a TLS-enabled `cmq_server`.
2. Send a 9-byte buffer: `0x16 0x03 0x03 0x00 0x04` (TLS 1.2
   Handshake record, length 4) followed by `0x02 0x00 0x00 0x00`
   (a ServerHello message with body length 0).
3. Server must cleanly reject without hanging.
