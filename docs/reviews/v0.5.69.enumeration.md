# v0.5.69 — HTTP/2 frame state machine (D2 phase 2)

## Scope
HPACK static codec exists. There is still no h2 preface,
frame parser, or stream table. This increment adds those
as a library. Huffman, the 4 KiB dynamic table, and a
listener/ALPN advertise stay deferred.

## Design (performance-first, safety, reliability)

- Preface is a 24-byte memcmp.
- Frame header is 9 bytes; payload cap 16 KiB.
- Max 32 concurrent streams (odd client ids only).
- First frame after preface must be SETTINGS (not ACK).
- Protocol errors move the conn to GOAWAY. No `h2` ALPN.
