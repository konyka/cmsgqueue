# v0.5.156 — apply MQTT maps on reload

## Goal

SIGHUP copies a non-empty `mqtt_bridge_maps` table
onto the live config. Count 0 / omitted keeps the
current rows. `..` / `\` / empty / qos outside 0–2
fail closed.

## Performance

Same-table compare avoids a heap copy. One `strdup`
pair per changed row.

## Security

`..` / `\` / controls / `,` fail closed. A failed
copy does not rewrite any live row.
