# v0.5.53 — Kafka-style key compaction (D6)

## Scope
v0.5.45 compact is tail-retain on the **live** WAL.
D6 keeps the last value per optional record key, and only
rewrites **sealed** `prefix.data.1` / `.idx.1`.

The live append path is unchanged (no extra compare).

D1–D5 stay deferred.

## Design (performance-first, safety, reliability)

- Key envelope: payload prefix `CMQK` + u16le key_len + key +
  value. No envelope → unkeyed, always kept.
- Empty value is a tombstone: drop that key.
- Last write wins. Rewrite `.1` via tmp + fsync + rename.
- Hold the filestore mutex so rotate cannot swap `.1` mid-pass.
- Bound key length (256) and record count (262144) to cap memory.
- CRC32 every source record; failure leaves `.1` untouched.
