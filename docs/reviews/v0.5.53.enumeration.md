# v0.5.53 — TLS 1.3 negotiation defensive test

## Scope

The existing `single_listener` test exercises a TLS handshake
but doesn't verify the negotiated protocol version. v0.5.46
added a TLS 1.2 cap for `verify_peer=1` (mTLS only), so plain
TLS should still negotiate TLS 1.3. This test adds an explicit
assertion that the negotiated version is TLS 1.3 (`0x0304`),
catching regressions where the cap accidentally leaks into
the plain TLS path.

## Test: `tls_e2e_handshake.tls13_negotiated`

The test uses a client that's pinned to TLS 1.3 only
(`SSL_CTX_set_min_proto_version(TLS1_3_VERSION)` +
`set_max_proto_version(TLS1_3_VERSION)`). The server has no
`tls_verify_peer`, so the v0.5.46 cap is not applied. After
the handshake, the test asserts `SSL_version(cssl) == 0x0304`
(TLS 1.3).

If a future refactor changes the SSL_CTX defaults to also
cap plain TLS at 1.2, this test fails with a clear assertion
error pointing at line 740.
