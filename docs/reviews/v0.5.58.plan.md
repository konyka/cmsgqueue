# v0.5.58 — KV last-value store

## Goal

`cmq_kv_put` / `get` / `del` keep one value per key. With a
persist directory the map survives destroy + recreate.

## Performance

Memory-only get/put: one mutex + linear probe of 256 slots.
Append happens only when persist is set.

## Security

Path checks reuse filestore create. Keys cannot contain
separators. Tombstones do not restore on replay.
