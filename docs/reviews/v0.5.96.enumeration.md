# v0.5.96 — COMPRESSED on PUBLISH (F2 follow-up)

## Scope
BATCH decompresses zstd. PUBLISH with the flag is still
`pending_error` (F11), so a client that compresses a single
publish is disconnected. This increment accepts the bit on
PUBLISH and inflates before subject parse.

MESSAGE / REQUEST stay rejected.

## Design (performance-first, safety, reliability)

- Parser: COMPRESSED allowed on BATCH or PUBLISH.
- `handle_publish` inflates once (16 MiB cap), clears the
  flag, recurses. Fanout is plaintext (no garbage).
- CHECKSUM still runs on the inflated payload.
- Uncompressed PUBLISH: one flag-bit compare.
