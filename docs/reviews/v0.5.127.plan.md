# v0.5.127 — reload log sinks

## Goal

SIGHUP can enable stdout or rotate `log_file` without
duplicating appenders.

## Performance

Off the PUBLISH path. One fopen + pointer swap per
changed file. Same-path reload is a strcmp.

## Security

Bad path / oversize path fails closed. Empty/omitted
does not remove a working sink.
