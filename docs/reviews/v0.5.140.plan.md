# v0.5.140 — bind h2_port on reload

## Goal

SIGHUP binds `h2_port` when create had no listener.
Existing accept fd is not rebound.

## Performance

One loopback `bind`/`listen` when starting. Existing
listener is one compare.

## Security

Non-loopback listen is rejected by `cmq_h2_listen`.
Out-of-range port fails closed. Empty/0 cannot close a
working listener.

- Unit tests green (including loopback apply).
- Push `v0.5.140` to `origin`.
