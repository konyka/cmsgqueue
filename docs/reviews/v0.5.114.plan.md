# v0.5.114 — listener TLS config keys

## Goal

`listener_count` and `listeners[1..3]` TLS paths have the
same config-file + ownership contract as `tls_ca`: load
owns, create strdup's, destroy frees.

## Performance

Up to twelve extra `strdup`s at create when slots 0–3 are
set. Hot path unchanged.

## Security

Empty cert/key/ca disable that string. `listener_count`
outside 0–4 and `tls_verify_peer` outside 0–1 fail closed.
Reload frees the prior heap before memset.
