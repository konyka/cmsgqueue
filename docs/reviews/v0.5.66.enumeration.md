# v0.5.66 — HPACK static codec (D2 phase 1)

## Scope
HTTP/2 needs HPACK before any `h2` ALPN advertise. This
increment is a static-table codec: integer, literal string
(no Huffman), and indexed headers. Dynamic table and the
h2 state machine stay deferred.

## Design (performance-first, safety, reliability)

- Integers capped at 2^20 (reject overflow).
- Huffman bit rejected (fail closed).
- Static table only (RFC 7541 Appendix A). Dynamic size 0.
- 4 KiB dynamic-table budget reserved for a later cut.
- Server still does not call `cmq_tls_set_alpn`.
