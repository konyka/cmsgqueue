# v0.5.169 — attach TLS session cache on reload

## Goal

Create and SIGHUP create the per-slot resumption cache
when load left it NULL so `new_cb` insert is not a
no-op. An existing cache is not remounted.

## Performance

Existing cache: one pointer check, no alloc.
First attach: one calloc plus mutex init.

## Security

NULL cfg fail-closes. Does not rewrite certs or drop
a live cache. Destroy frees owned `SSL_SESSION*`.
