# v0.5.163 — attach txn coordinator on reload

## Scope
Create calls `cmq_txn_create` always. Reload only called
`cmq_txn_reload_attach_log`, which fail-closes when `txn`
is NULL and `persist_dir` is set. A live filestore whose
coordinator was never allocated then blocked every SIGHUP.

## Design (performance-first, safety, reliability)

- `cmq_txn_reload_attach`: existing coordinator is left
  alone (no remount). Creates when `*t` is NULL.
- Create miss fail-closes. Persist attach stays 159.
- In-memory BEGIN works without a log.
