# v0.5.82 — JWKS refresh

## Goal

A configured `jwks_refresh_sec` re-GETs `jwks_url` and
atomically publishes the new key set to CONNECT.

## Performance

Interval 0: no thread, one pointer on CONNECT. Refresh I/O
runs on the sidecar, never on offer/PUBLISH.

## Security

Parse failure keeps the previous keys. No userinfo. Caps
unchanged. Minimum interval 5 seconds.

## Stop

- Unit tests green (new + existing JWKS fetch).
- Push `v0.5.82` to `origin`.
