# v0.5.137 — reload jwks_url

## Scope
Create parses `jwks_url`, GETs once, and starts the
sidecar. Reload updated interval and CA only, so SIGHUP
could not point the next refresh at a new host.

## Design (performance-first, safety, reliability)

- `cmq_jwks_refresh_reload_url`: empty/omitted keeps.
  `cmq_jwks_parse_url` rules fail closed.
- Copies host/path/port/tls onto a live sidecar under the
  same mutex as CA. Existing CA is preserved.
- Does not re-GET. Sidecar start stays create-time.
