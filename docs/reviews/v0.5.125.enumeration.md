# v0.5.125 — reload account_max_* defaults

## Scope
Create calls `cmq_account_manager_set_defaults` and
`set_default_bytes_live` from `account_max_connections`,
`account_max_subscriptions`, `account_max_payload`, and
`account_max_bytes_live`. Reload never updated the manager,
so new accounts after SIGHUP still inherited create-time
caps.

## Design (performance-first, safety, reliability)

- In-place atomic stores on the manager defaults.
- 0 / omitted keeps the current field.
- Existing accounts keep their copied limits (same as
  `set_defaults` today — new / reclaimed slots only).
- Out-of-range values fail closed.
