# v0.5.46 — MQTT will / sessions

## Goal

Parse CONNECT correctly, publish a last-will on abnormal
disconnect, and keep subscription filters when Clean Session=0.

## Performance

- CONNECT-only work (rare).
- Tables are fixed arrays + one mutex; no hash, no heap on
  the cmq hot path.

## Security

- Reserved CONNECT flag bit fails closed.
- Will payload size-capped (CWE-400).
- Auth uses Username/Password flags, not Will/Clean bits.
