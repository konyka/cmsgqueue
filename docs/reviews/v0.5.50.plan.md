# v0.5.50 — F14 connect-rate on CONNECT

## Goal

`max_connections_per_account` actually limits CONNECT attempts
per second, as documented.

## Performance

Disabled (quota pointer NULL): one compare. Enabled with
`max_connects == 0`: one integer compare. Enabled: existing
open-address slot CAS (same as publish quota).

## Security

Rate-limit before concurrent credit. Fail-open if the slot table
is full (same as publish). Audit on reject.
