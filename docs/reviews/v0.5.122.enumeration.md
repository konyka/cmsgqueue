# v0.5.122 — reload live rate / timeout scalars

## Scope
Accept reads `max_connects_per_sec`, REQUEST reads
`inbox_max_pending`, and the keepalive tick reads
`ping_interval_ms` / `write_timeout_ms` from live
`srv->config`. `cmq_server_reload` loaded those keys
into `fresh` and freed them.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_limits` copies non-zero fresh
  scalars onto the live config.
- 0 / omitted keeps the current value (a file that
  leaves a key out must not disable a working cap).
- Out-of-range values fail closed with no copies.
