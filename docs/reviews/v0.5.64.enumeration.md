# v0.5.64 — OTLP/HTTP JSON exporter (D1 phase 2)

## Scope
The span ring and sidecar are live. Export is still a no-op
hook. This increment encodes spans as OTLP/JSON and POSTs
them to `otlp_endpoint` (`http://host[:port][/path]`).

gRPC, TLS collectors, and consume-span offer stay deferred.

## Design (performance-first, safety, reliability)

- No endpoint: export hook stays NULL (one pointer).
- Encode and POST run only on the sidecar.
- `http://` only; no userinfo; path rejects CR/LF/`..`.
- Spans still carry trace/kind/time only (no payload).
- HTTP failure is ignored; the ring never blocks.
