# v0.5.91 — JWT ES256 / RS256 issuing (D3 follow-up)

## Scope
HS256 mint is live. ES256 / RS256 CONNECT still needs
tokens minted elsewhere. This increment signs with a
P-256 scalar or RSA `n`/`e`/`d`.

## Design (performance-first, safety, reliability)

- ES256: 32-byte `d`; JWS is raw R||S (64).
- RS256: PKCS#1 v1.5; `n` 256–512 bytes.
- Same `iss`/`sub`/`exp` rules as HS256 mint.
- Verify path unchanged. Not on PUBLISH.
