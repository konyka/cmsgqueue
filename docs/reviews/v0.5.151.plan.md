# v0.5.151 — set h2 ALPN on reload

## Goal

SIGHUP adds `h2` ALPN when an existing TLS slot has none
and h2 is now listening. Existing ALPN is not remounted.

## Performance

One `SSL_CTX` rebuild per empty slot. Existing ALPN is
one length compare.

## Security

`..` / `\` fail closed. Empty/omitted cannot drop a
working ALPN list.

- Unit tests green (including PEM apply).
- Push `v0.5.151` to `origin`.
