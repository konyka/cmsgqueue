# v0.5.56 — Durable stream consumer cursors (D4 phase 1)

## Scope
`cmq_stream` already has in-memory consumers and ack watermarks.
They die with `cmq_stream_destroy`. D4 phase 1 persists those
cursors so a reopen resumes the same seq.

KV / object store and a partition model stay deferred.

## Design (performance-first, safety, reliability)

- Opt-in: `cmq_stream_set_cursor_path(dir)`. Default create
  does no I/O (append path unchanged).
- Persist only on add / ack / remove (not append).
- File `{dir}/{name}.cursors`: tmp + fsync + rename.
- Load on set_path. Missing file is empty.
- Reject `..` / separators in dir and stream name.
- Consumer names with space or `/` are not written.
