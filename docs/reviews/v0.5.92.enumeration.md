# v0.5.92 — Connect spans (D1 follow-up)

## Scope
`KIND_CONNECT` is on the ring and in OTLP encode, but
CONNECT never offers it. This increment offers one connect
span after CONNACK 0.

## Design (performance-first, safety, reliability)

- One connect span per successful handshake (CONNACK 0).
- Same 16-byte accept `trace_id`.
- CONNACK != 0: no span.
- `otel == NULL`: no-op.
- Offer stays non-blocking; drop-newest unchanged.
