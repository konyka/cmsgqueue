# v0.5.152 — apply config_file on reload

## Goal

SIGHUP copies a new `config_file` onto the live config so
the next reload opens that path. Empty/omitted keeps the
current file.

## Performance

Same-string compare avoids a heap copy. One `strdup` on
a real retarget.

## Security

`..` / `\` / controls fail closed. A failed reload does
not retarget the next SIGHUP.
