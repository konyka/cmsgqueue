# v0.5.70 — KV/object REQUEST-get (D4 phase 6)

## Scope
PUBLISH writes `$KV` / `$OBJ`. REQUEST still fans out to
subscribers. This increment answers REQUEST on those
subjects from the store (hit or empty miss).

## Design (performance-first, safety, reliability)

- Non-`$` REQUEST: unchanged.
- `$KV.` / `$OBJ.` parse, then get. Miss is an empty body.
- Reply is a MESSAGE to the request `reply-to` on the same
  client. Inbox pending is decremented (no later RESPONSE).
- No reply-to: fail closed.
