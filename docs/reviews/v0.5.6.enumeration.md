## P1 — RWLOCK fairness on sublist

- **gap** → `src/server/cmq_sublist.c:24, 433` (cmq_rwlock_t uses
  pthread_rwlock; writers can starve readers under continuous
  subscribe/unsubscribe churn).
- **impact**: publish latency spikes during high churn.
- **effort**: M (depends on cmq_rwlock_t implementation; may need
  spinlock-protected reader-count fallback).

## P1 — WS permessage-deflate

- **gap** → `src/server/cmq_ws.c` (extend WebSocket handshake to
  negotiate `permessage-deflate; server_no_context_takeover`).
- **impact**: bandwidth waste on WS clients (especially mobile).
- **effort**: L (deflate state per connection + flush boundary).

## P1 — Multi-threaded accept loop

- **gap** → `src/server/cmq_server.c:712, 7069` (single listen fd
  registered with the ev_loop; the accept_cb runs on the ev_loop
  thread). High-conn-rate servers bottleneck.
- **impact**: 100K+ conn/sec can't be served.
- **effort**: L (multi-threaded accept + per-conn handoff to worker pool).

## P1 — Multi-listener runtime accept loop

- **gap** → `src/server/cmq_server.c:7027` (cmq_server_run binds only
  `listen_fds[0]`; slots[1..3] are reserved but never bound).
- **impact**: cannot serve two distinct certs/ports from one process.
- **effort**: M (200 LOC: iterate slots, per-listener accept_cb dispatch).

## P1 — F19b full bridge: real cmq_sublist_insert

- **gap** → `src/enterprise/cmq_mqtt_server.c:627` (the relay
  function pointer target is `relay_insert_cb` (no-op) unless
  `cmq_mqtt_register_sublist_insert` is called from cmq_server).
  If the cmq server doesn't wire this, the relay silently drops
  bridge publishes.
- **impact**: F19b no-op at runtime if the wiring is missing.
- **effort**: S (call `cmq_mqtt_register_sublist_insert(&cmq_sublist_insert, srv->sublist)` from cmq_server_create).

## P1 — MQTT 5.0 properties decode on SUBSCRIBE

- **gap** → `src/enterprise/cmq_mqtt_server.c:524` (mqtt_v5_props_skip
  flag exists but isn't honored in the SUBSCRIBE handler).
- **impact**: 5.0 SUBSCRIBE failure.
- **effort**: XS.

## P2 — cmq_atomic_u64 portability on 32-bit

- **gap** → `src/core/cmq_atomic.h` (assume _Atomic uint64_t is
  always available; not portable to -m32 if it's not).
- **impact**: potential build failure on 32-bit targets.
- **effort**: XS (PDF detection + fallback).

## P2 — handle_publish: freelist for worker_msg_t

- **gap** → `src/server/cmq_server.c:905` (worker_push_msg calls
  `malloc(sizeof(cmq_worker_msg_t))` on every delivery).
- **impact**: malloc contention under high publish rate.
- **effort**: S (per-worker freelist).

## P2 — rate-limit mutex removed

- **gap** → `src/enterprise/cmq_mqtt_server.c:114` (the rate-limit
  check holds a single global mutex; under many clients that's
  contention).
- **impact**: lock contention at high client count.
- **effort**: S (per-thread LRU with sharded mutex or stdatomic).

## P3 — close-by-fd verification

- **gap** → verify `src/server/cmq_server.c` cmq_clients[] uses
  fd+gen and that close_cb runs before fd reuse.
- **impact**: rare race.
- **effort**: S (test only).

## P3 — log under hot path

- **gap** → `src/enterprise/cmq_tls.c:266` (cmq_log_info on
  cmq_tls_set_crl(NULL) writes to stderr per call).
- **impact**: log spam under bulk config reload.
- **effort**: XS (rate-limit log).

## P3 — stats counter on worker thread

- **gap** → `src/server/cmq_server.c:2211` (stat_messages_out
  increments in deliver_targets_sync, called from the worker
  thread context). The counter is per-server, not per-thread.
- **impact**: min — benign.
- **effort**: XS.

## P3 — TLS session_init latency

- **gap** → `src/enterprise/cmq_tls.c` (SSL_CTX_load_verify_locations
  + SSL_CTX_set_alpn_protos are called fresh per session).
- **impact**: TLS handshake latency.
- **effort**: M (cache + per-session hook).

## P2 — Non-blocking mqtt_bridge cleanup

- **gap** → `src/enterprise/cmq_mqtt_server.c` (relay thread
  processes one entry per iteration; the bridge queue growing
  unbounded is bounded by 256 but the worker keeps pace).
- **impact**: bounded.
- **effort**: XS.

## P3 — 5.0 fan-out wildcard puback

- **gap** → `src/enterprise/cmq_mqtt_server.c` (no PUBACK for the
  multi-level wildcard "*" topic).
- **impact**: 5.0 compliance gap.
- **effort**: M.
