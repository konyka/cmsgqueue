# v0.5.49 — Publish-side subject rewrite

## Goal

Operators can remap a published subject per account before
match/delivery (`foo.*` → `bar.$1`), without a lock on the
no-map publish path.

## Performance

- No maps: one atomic load of `map_total`.
- Maps: one extra manager lock on CONNECT-authenticated publish
  (same lock family as export ACL).

## Security

- ACL on the wire subject; maps are admin-trusted.
- Overflow / empty rewrite is a hard reject, not a truncate.
