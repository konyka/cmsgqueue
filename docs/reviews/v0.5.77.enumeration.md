# v0.5.77 — docs-only release (test suite stabilization)

## Scope

v0.5.77 ships docs-only. The test suite `tests/test_tls_e2e_handshake.c`
has grown to 28 defensive tests covering v0.5.45 through v0.5.76.
This round commits:

- Two bench transcripts (pre-/post-additions).
- A CHANGELOG entry summarizing the recent test coverage.
- This enumeration doc.

No production change, no test change.

## What v0.5.77 captures

This is a stabilization point — the defensive test matrix covers
the major production failure modes that the v0.5.46–v0.5.73 production
fixes targeted:

- Handshake hang (v0.5.45 fix, v0.5.50 test)
- mTLS bypass (v0.5.46 fix, v0.5.46 test)
- CRL bypass (v0.5.47 fix, v0.5.55 test)
- Close-notify loss (v0.5.72 fix, v0.5.72 test)
- Cipher ordering / cap enforcement (v0.5.58 fix, v0.5.58 test)
- Config validation (v0.5.60/61 tests)

## Deferred (unchanged)

- TLS 1.3 mTLS via post-handshake auth (v0.5.48/v0.5.49 race).
- Per-listener `accept_thread_func` refactor (already on remote
  workstream as v0.5.42).
- Concurrent graceful-shutdown test (framework timing issue).
- Invalid CA bundle rejection test (OpenSSL state issue).
- TLS 1.3 session ticket resumption test (server doesn't issue tickets).
