# v0.5.77 — JWT RS256 (D3 phase 7)

## Scope
CONNECT JWT verify is HS256 / ES256. Many IdPs mint RS256.
This increment verifies compact RS256 (2048–4096 bit) and
parses JWKS `kty=RSA` keys. `jwt_rsa_n` / `jwt_rsa_e` are
base64url modulus and exponent.

HTTPS JWKS stays deferred.

## Design (performance-first, safety, reliability)

- No RSA key: existing HMAC / ES256 / nkey paths unchanged.
- RS256 only when `alg` is RS256. No algorithm confusion.
- `n` must decode to 256–512 bytes. `e` is 1–8 bytes.
- JWKS RSA: `n` + `e` required. `k`-only RSA still rejected.
- Verify-only (no issue). OpenSSL EVP, no deprecated RSA_*.
