# v0.5.174 — quote INFO checksum JSON

## Scope
F4 advertises `"checksum":"crc32c"`. `send_info_frame`
used `"checksum":%s` with `crc32c`, so the live INFO
payload was invalid JSON (`"checksum":crc32c`). Clients
that parse INFO strictly could not see F3.

## Design (performance-first, safety, reliability)

- `cmq_info_json_str`: apply quotes the token;
  0 / omitted / empty writes `""`; quote, backslash,
  controls, or overflow fail closed.
- `send_info_frame` quotes checksum through the
  helper. Compression stays the existing quoted
  format string.
- One INFO per CONNECT; no per-message cost.
