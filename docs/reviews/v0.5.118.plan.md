# v0.5.118 — SIGHUP / config_file

## Goal

SIGHUP during `cmq_server_run` reloads the stored
`config_file` (load path by default).

## Performance

One atomic CAS per event-loop tick when the flag is set.
Handler only stores 1. Hot path unchanged when idle.

## Security

`config_file` rejects `..` and `\\`. Empty disables
SIGHUP reload. The handler does not touch heap.
