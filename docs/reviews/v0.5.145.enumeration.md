# v0.5.145 — fetch JWKS on reload

## Scope
Create GETs `jwks_url` into the cache. v0.5.141 starts a
refresher only when a cache already exists, so SIGHUP
could not load keys when create had none.

## Design (performance-first, safety, reliability)

- `cmq_jwks_reload_fetch`: empty/omitted keeps off.
  Bad URL or GET fail closed.
- Allocates a cache only when `*cache` is NULL. Existing
  cache (static JSON or prior GET) is left alone.
- Does not start the refresher (v0.5.141).
