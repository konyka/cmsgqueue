# v0.5.69 — HTTP/2 frame state machine

## Goal

A connection that sends the RFC 7540 preface and SETTINGS
can open at most 32 streams.

## Performance

No heap per frame. Stream table is 32 slots.

## Security

Preface mismatch, oversize frames, even client stream ids,
and a 33rd stream fail closed.
