# CMSGQueue v0.5.2 — Remaining Gap Enumeration

**Scope.** Items explicitly deferred from v0.5.1 plus any new gaps
discovered against NATS / Kafka / Redis Pub-Sub feature sets.

## Source of "deferred" list

- `docs/reviews/v0.5.1.bundle.md` — adversarial consensus. Notably:
  F19 split into P4a (skeleton + QoS0/1, **shipped**) and P4b (QoS2 +
  5.0 props, **deferred**).
- `docs/adr/0016-async-wal-ring.md` — the cached-offset fix was
  partial; "True async ring (SPSC + worker)" is the v0.6 / v0.5.2
  follow-up.
- `docs/reviews/v0.5.1.plan.md` P7 micro-plan notes "stable partitions"
  were not implemented in v0.5.1 (only bulk-read of chunks).
- `src/enterprise/cmq_mqtt_server.c:145` — PUBLISH bridge to
  cmq_sublist is deferred (no server_t* param).
- `src/enterprise/cmq_mqtt_server.c:153` — QoS2 disconnects.
- `src/server/cmq_server.h` CMQ_MAX_LISTENERS=4, only slot[0] wired
  in v0.5.1 (`docs/adr/0010-per-listener-ssl-ctx.md`).
- `src/enterprise/cmq_tls.c:137` — no CRL/OCSP callback registered
  (ADR 0010 mentions but doesn't ship).
- `src/enterprise/cmq_mqtt_server.c:188` — listener binds
  127.0.0.1:1883 plaintext with no auth (anyone on host can
  publish).

## P1 — F19b MQTT PUBLISH→cmq_sublist bridge + SUBSCRIBE wire-up

- **gap** → `src/enterprise/cmq_mqtt_server.c:144` (PUBLISH does not
  insert into cmq_sublist; SUBACK/SUBSCRIBE never dispatched) →
  **impact**: server-side MQTT broker accepts but does not route
  messages to cmq subscribers; the protocol is useless without a
  bridge → **effort**: L

## P1 — Async WAL ring (full SPSC + worker thread)

- **gap** → `src/store/cmq_filestore.c:436` (still inline
  flock+fflush per publish; v0.5.1 only cached EOF offsets per
  ADR 0016) → **impact**: ~250-500 µs/publish on the WAL path
  remains; bench still flat vs v0.5.0 → **effort**: L

## P1 — MQTT listener auth + TLS (1883 plaintext)

- **gap** → `src/enterprise/cmq_mqtt_server.c:181` (binds plaintext,
  no token / cert check) → **impact**: anyone on the host can
  publish/subscribe; security regression vs cmq_server which has
  auth + TLS → **effort**: M

## P1 — WAL replay partition-parallel

- **gap** → `src/server/cmq_server.c:6718` (bulk-read but
  single-threaded dispatch; per the plan P7 "stable partitions" +
  "bounded worker count") → **impact**: 100K-record WAL startup
  still ~30s; bounded by single worker → **effort**: M

## P2 — Multi-listener: slots[1..3]

- **gap** → `src/server/cmq_server.h:165` CMQ_MAX_LISTENERS=4,
  `src/server/cmq_server.c:6672` only slot[0] assigned →
  **impact**: cannot serve two certs / ports from one process →
  **effort**: M (depend on per-listener SSL_CTX generation swap)

## P2 — MQTT QoS2 state machine

- **gap** → `src/enterprise/cmq_mqtt_server.c:152` (QoS 2 rejected
  with disconnect) → **impact**: no PUBREC/PUBREL/PUBCOMP, no exactly-
  once delivery → **effort**: M

## P2 — Custom CRL/OCSP for mTLS

- **gap** → `src/enterprise/cmq_tls.c:136-140` (CA loaded,
  SSL_CTX_set_verify enabled, but no cert_verify_cb for CRL) →
  **impact**: revoked certs still accepted → **effort**: S

## P3 — MQTT 5.0 properties parser

- **gap** → `src/enterprise/cmq_mqtt_server.c` (parses only MQTT
  3.1.1; 5.0 property length-prefixed regions never decoded) →
  **impact**: 5.0 clients can't send response-topic, message-expiry,
  user-properties → **effort**: M

## P3 — QG dedup O(n²) hot path

- **gap** → `src/server/cmq_server.c:1916` (inner scan + strcmp per
  QG member; bundle perf #2) → **impact**: 10K subs × 100 groups
  ~40-200K cycles/publish → **effort**: M

## P3 — fsync policy option

- **gap** → `src/store/cmq_filestore.c:503` (no fsync today; ADR 0016
  notes "if fsync desired, that's a separate feature") →
  **impact**: OS crash loses page-cache window → **effort**: S

## P4 — Per-target copy coalescing

- **gap** → `src/server/cmq_server.c:925` (worker_push_msg malloc +
  memcpy per target; bundle perf #3) → **impact**: ~2-6K cycles per
  target on hot path → **effort**: S

## P4 — RETAIN support

- **gap** → `src/enterprise/cmq_mqtt_server.c` (no retained-message
  storage; MQTT retain flag ignored) → **impact**: MQTT retain
  semantics missing → **effort**: M

## P4 — STATS counter accuracy under replay

- **gap** → `src/server/cmq_server.c:2940` (stat_messages_in
  increments for replayed records; doesn't distinguish live from
  replay) → **impact**: metrics overcount "real" publishes → **effort**: S

## P5 — WebSocket binary frame finalization

- **gap** → check `src/server/cmq_ws.c` for fragmented-frame
  reassembly; bundle notes "WebSocket transport with frame
  reassembly" already shipped but edge cases? → **impact**: TBD →
  **effort**: S (likely already done)
