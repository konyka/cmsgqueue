# v0.5.174 — quote INFO checksum JSON

## Goal

The live INFO frame emits `"checksum":"crc32c"`
as documented. Omitted / empty helper input
writes `""`. Bad tokens fail closed.

## Performance

One quote + `snprintf` per CONNECT. No per-message
path.

## Security

Quote, backslash, and control bytes are rejected
so a later config-driven token cannot break out
of the JSON string.
