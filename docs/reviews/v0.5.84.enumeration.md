# v0.5.84 — OTLP/gRPC (D1 phase 4)

## Scope
OTLP export is HTTP/JSON only. Collectors also speak
OTLP/gRPC on port 4317. This increment encodes a protobuf
`ExportTraceServiceRequest` and POSTs it as an HTTP/2
gRPC message.

## Design (performance-first, safety, reliability)

- `grpc://host[:port][/path]`. Default port 4317. Default
  path is the TraceService Export method.
- Protobuf + 5-byte gRPC frame. No JSON on this path.
- Prior-knowledge HTTP/2 POST. 200 ms I/O. Failures ignored.
- `http(s)://` JSON path unchanged. No userinfo.
