# v0.5.98 — COMPRESSED on REQUEST (F2 follow-up)

## Scope
PUBLISH / MESSAGE inflate. REQUEST with the bit is still
`pending_error`, so a compressed request is disconnected.
This increment accepts the bit and inflates before subject
parse.

RESPONSE stays rejected.

## Design (performance-first, safety, reliability)

- Parser: COMPRESSED on BATCH, PUBLISH, MESSAGE, REQUEST.
- `handle_request` inflates once (16 MiB), clears the flag,
  recurses. Inbox budget runs on the plaintext path.
- Uncompressed REQUEST: one flag-bit compare.
