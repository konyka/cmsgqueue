# v0.5.111 — MQTT bridge config-file keys (F6 follow-up)

## Scope
`mqtt_bridge_addr` / `mqtt_bridge_port` were only settable
from C. The parser ignored both keys, so a conf-only
operator could not enable the outbound MQTT bridge.

## Design (performance-first, safety, reliability)

- Empty addr means disabled (NULL). Port 0–65535 (0 = off).
- Addr rejects `/`, `\`, controls, spaces, and length ≥ 256.
- `cmq_config_free` owns the string. `cmq_server_create`
  `strdup`s it so destroy cannot free a caller literal.
- Server connect path is unchanged (best-effort).
