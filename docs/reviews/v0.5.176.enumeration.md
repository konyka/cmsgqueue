# v0.5.176 — wire INFO server_id from cluster_node_id

## Scope
F4 INFO advertised `"server_id":"cmsgsrv"` even when
create had `cluster_node_id`. Mesh clients that key
off INFO could not tell nodes apart.

## Design (performance-first, safety, reliability)

- `cmq_info_server_id_json`: 0 / omitted / empty is
  `"cmsgsrv"`. Apply quotes a live node id.
- Longer than `CMQ_NODE_ID_SIZE-1`, quote, backslash,
  or controls fail closed (no INFO).
- Reload attach of cluster does not remount a live
  node id; INFO reads the live config string.
