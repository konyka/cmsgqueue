# v0.5.129 — audit file from persist_dir

## Scope
`cmq_audit.h` says the file sink is `{persist_dir}/cmq-audit.log`
when persist_dir is set. Create logged persist events but never
called `cmq_audit_set_path`. The file was unreachable from
`cmq.conf` / create.

## Design (performance-first, safety, reliability)

- `cmq_audit_from_persist(dir)` writes `{dir}/cmq-audit.log`.
  NULL/empty disables. `..` / `\` / controls fail closed and
  leave the current path.
- Create calls it after the WAL opens (dir already validated).
- Destroy clears the global path so the next process does not
  keep the old file.
- Reload uses `cmq_audit_reload_persist`: omitted/empty keeps
  the current file. WAL remount stays create-time.
