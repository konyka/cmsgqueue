# v0.5.104 — Durable `$JS` history WAL

## Goal

Pull consume `$JS.<name>.<consumer>` returns the same
seq/payload after reopen when `persist_dir` is set.

## Performance

One extra append+fsync on `$JS` PUBLISH only.
Non-`$JS` subjects unchanged. Replay is once per
lazy open.

## Security

Names stay `[A-Za-z0-9_-]`. Path is `{persist_dir}/js`.
Corrupt `CMQM` stops replay (keep what landed).
