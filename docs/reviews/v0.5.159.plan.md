# v0.5.159 — attach txn log on reload

## Goal

SIGHUP enables `{persist_dir}/cmq.txn` when create left
the txn log unset. Empty / omitted keeps off. An
existing log is not remounted. `..` / `\` fail closed.

## Performance

Existing log: one pointer check, no fopen.
First attach: one path copy + optional load of
committed ids (no re-fanout).

## Security

`..` / `\` / controls fail closed. Does not rewrite
live `persist_dir`.
