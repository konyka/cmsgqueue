## 4. Per-P-item Micro-Plans

### P1 CRL X509_STORE integration
- **Goal**: `src/enterprise/cmq_tls.c:139` — actually load the CRL into the SSL_CTX's X509_STORE.
- **Implementation**: in `tls_build_ssl_ctx`, when `cfg->ca` is set, call `SSL_CTX_load_verify_locations` with FILETYPE_PEM, then `X509_STORE_add_crl` if a CRL path is configured. ~30 LOC.
- **RED**: `tests/test_mtls_api.c::crl_revoked_cert_rejected` — generate CA, sign a cert, revoke it via openssl ca, load CRL, assert handshake fails.
- **Atomic**: `fix(P1): actually load CRL into X509_STORE`.

### P2 cmq_rch leak/UAF test
- **Goal**: `src/util/cmq_rch.h` — abuse paths untested.
- **Implementation**: write `test_rch_overflow` that double-releases, exceeds the initial refcount, etc. Run under ASAN.
- **Atomic**: `test(P2): cmq_rch abuse paths (ASAN)`.

### P2 STATS replay counter accuracy
- **Goal**: `src/server/cmq_server.c:6798` — move the `stat_messages_replayed` increment inside `replay_one_record` to AFTER `handle_publish` succeeds.
- **Implementation**: 5 LOC.
- **RED**: `tests/test_wal_replay.c::stats_skip_malformed` — write a record with `payload_len < 9`, restart, assert `stat_messages_replayed == 0`.
- **Atomic**: `fix(P2): stat_messages_replayed only on successful replay`.

### P2 subject_rl hash collision test
- **Goal**: `src/server/cmq_subject_rl.c:55` — confirm FNV-1a collisions don't allow bypass.
- **Implementation**: write `test_subject_rl_collisions` that constructs N subjects and asserts admitted ≤ max.

### P1 F19b full MQTT bridge

## 6. Risk Register

| Item | Risk | Mitigation |
|---|---|---|
| P1 F19b bridge | Inserting a sub-ref per topic explodes sublist | Coalesce identical topics in LRU; per-publisher dedup |
| P1 CRL | CRL parse failure crashes startup | Eager load at startup; on failure log + disable CRL, not refuse |
| P1 multi-listener | Two reloads race | Per-listener cmq_rch handle; same swap as v0.5.1 P1 |
| P2 backpressure | Bounded wait masks real bugs | Add stat_async_blocked counter; log when > threshold |
| P1 QoS2 retransmit | Map grows unbounded | Bounded LRU + cleanup on disconnect |

## 9. Stop Conditions

- RED test fails for a reason other than the documented defect.
- Production code proposed before RED test lands.
- Default ctest regresses or discovery drops below 65.
- TSAN reports new race.
- ASAN or UBSAN reports error on changed path.
- Bench regresses > 10%.
- P1 F19b bridge cannot preserve per-publisher sublist cleanup.
- P1 multi-listener cannot keep two reloads independent.
- P1 QoS2 retransmit produces non-idempotent state.
- Any proposed change creates a 14th P-item; submit to a new adversarial round.
