# v0.5.146 — bind extra listeners on reload

## Scope
Create binds `listener{1,2,3}` when `listener_count` > 1.
Reload ignored those slots, so SIGHUP could not enable an
extra bind when create had none.

## Design (performance-first, safety, reliability)

- `cmq_listener_reload_bind`: empty host and port 0 keep
  off. Non-IPv4 / bad port fail closed.
- Binds only when `*lfd < 0`. Existing accept fd is left
  alone (no rebind).
- Server `ev_add`s a newly bound fd when the loop is live.
  Slot 0 stays create-time.
