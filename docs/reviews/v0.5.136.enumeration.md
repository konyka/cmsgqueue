# v0.5.136 — reload MQTT bridge addr/port

## Scope
Create dials `mqtt_bridge_addr`:`mqtt_bridge_port`. Reload
updated maps only, so SIGHUP could not move the outbound
broker.

## Design (performance-first, safety, reliability)

- `cmq_mqtt_reload_endpoint`: empty/omitted addr and port
  0 keep the current endpoint.
- A new IPv4 + port 1–65535 calls `cmq_mqtt_bridge_connect`
  (already reconnects on endpoint change; same live peer
  is a no-op).
- Non-IPv4 / bad port fail closed and leave the current
  strings. A failed dial does not rewrite live config.
