# v0.5.168 — attach log on reload

## Goal

SIGHUP creates the logger when create left `log` NULL
so sink reload does not fail-close the whole apply.
An existing logger is not remounted.

## Performance

Existing log: one pointer check, no alloc.
First attach: one malloc plus mutex init.

## Security

NULL `**log` and level outside 0–5 fail-closed.
Does not rewrite sinks or drop a live logger.
