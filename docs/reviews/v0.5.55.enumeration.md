# v0.5.55 — Idempotent publish (D5 phase 1)

## Scope
D5 is exactly-once / transactions. There is no PID+seq window
and no txn coordinator. This increment ships the **first**
designed step: a sliding window per publisher id.

Transactions stay deferred (need D4's log).

## Design (performance-first, safety, reliability)

- Optional header prefix `CMQI` + u32be pid + u64be seq (16 B).
- No `CMQ_FLAG_HEADERS` / no magic: zero extra work after the
  existing flag check.
- Per-pid window of 64 seqs. Seen → drop (no fanout, no WAL).
- Unseen in-window out-of-order is accepted once.
- Older than the window is treated as a duplicate.
- 256 pid slots, mutex only when a header parses. Table full
  rejects that pid (fail closed for EOS, not silent admit).
