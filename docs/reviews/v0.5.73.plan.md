# v0.5.73 — HTTP/2 dedicated listener

## Goal

A loopback h2 port accepts prior-knowledge preface/SETTINGS
and turns one POST into a subject + payload.

## Performance

One 16 KiB recv buffer. Poll 200 ms. No per-frame heap.

## Security

Loopback bind only. Path traversal and wildcard subjects
fail closed. No ALPN advertise.

- Unit tests green (new + h2).
- Push `v0.5.73` to `origin`.
