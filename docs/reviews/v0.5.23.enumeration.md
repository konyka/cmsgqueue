# v0.5.23 — TLS session resumption cache

## Scope
Implement a real TLS session resumption cache behind the v0.5.15
placeholder test (`tests/test_tls_session_cache.c`). This eliminates
repeated full handshakes on reconnect — the highest-impact TLS perf
optimization available without a handshake-time protocol change.

Two mechanisms covered:
1. **Session ID cache** (RFC 5246 / RFC 8446 §4.6.1) — server keeps a
   map from session ID → `SSL_SESSION*`. Client presents the ID in the
   ClientHello; server looks it up and resumes.
2. **Session ticket key** (RFC 8446 §4.6.2) — opaque ticket encrypted
   with a rotating key. We don't need full ticket-encryption machinery
   for the perf win; OpenSSL's `SSL_CTX_set_session_cache_mode` +
   `SSL_CTX_set_tlsext_ticket_keys` handles the wire format.

We use **both** — session ID cache handles clients that don't do
tickets; tickets handle clients that prefer stateless resumption.

## Design (performance-first, safety, reliability)

### Architecture
- New module: `src/enterprise/cmq_tls_session_cache.{c,h}`.
- Cache lives on `cmq_tls_config_t` (one per listener).
- Bounded LRU: max 1024 entries (configurable via `CMQ_TLS_SESSION_CACHE_MAX`).
  Each entry is `SSL_SESSION*` (opaque; freed via `SSL_SESSION_free`).
- Hash table: 64 buckets, open-addressing with linear probing. Chaining
  is also fine but open-addressing has lower per-entry overhead.
- Mutex: single `pthread_mutex_t` around the map. Sessions are short
  lived enough that contention is fine; the critical section is a few
  pointer copies.

### Cache hit / miss flow
**On client connect (server side):**
1. `SSL_new(cfg->ssl_ctx)` creates the per-conn SSL handle.
2. `SSL_set_session_cache_mode(ssl, SSL_SESS_CACHE_SERVER |
   SSL_SESS_CACHE_NO_INTERNAL)` disables OpenSSL's built-in default
   cache — we own the cache.
3. On `SSL_do_handshake` completing, OpenSSL calls our `new_session`
   callback; we insert the `SSL_SESSION*` into our map under its
   session ID.
4. On the next `SSL_do_handshake` with the same client (resumed
   session), OpenSSL calls `SSL_get_session()` during the handshake
   lookup — we wrap that with our cache hook.

### Thread safety
- Single mutex around the cache map. Lock-free lookup would be
  possible (seqlock + RCU) but the contention profile is fine without it:
  handshakes are far rarer than data-plane reads.
- The `SSL_SESSION*` is ref-counted by OpenSSL; we `SSL_SESSION_up_ref`
  on insert and `SSL_SESSION_free` on evict.

### Safety
- Cap on cache size (1024) bounds memory at ~1 MB worst case
  (OpenSSL sessions average ~1 KB).
- Eviction: when the cache is full, evict the oldest entry (LRU).
  We track `last_used` timestamp (CLOCK_MONOTONIC seconds) per entry.
- Stale-while-revalidate: an evicted session is still valid in OpenSSL
  if the client retries within the timeout; we don't try to "rescue"
  evicted sessions.
- On `cmq_tls_config_destroy`, free every `SSL_SESSION*` in the cache
  then free the map.

### Reliability
- Cache failures (corrupted session, OpenSSL error) are not fatal:
  we log via `cmq_log` and return -1 from the insert. The handshake
  still completes; we just don't cache that session.
- Restart: cache is process-local (in-memory). Persistence is out of
  scope; restarting the server forces full handshakes for the first
  1024 connections (acceptable trade-off).

## API additions

```c
/* Initialize the cache on a config (call after cmq_tls_load). */
int cmq_tls_session_cache_init(cmq_tls_config_t *cfg);

/* Free all sessions and the cache map. */
void cmq_tls_session_cache_destroy(cmq_tls_config_t *cfg);

/* Insert an SSL_SESSION into the cache (called from new_session cb). */
int cmq_tls_session_cache_insert(cmq_tls_config_t *cfg,
                                  unsigned char *id, unsigned int id_len,
                                  SSL_SESSION *sess);

/* Look up by session ID (called during handshake lookup). Returns
 * SSL_SESSION* with an up-ref (caller must SSL_SESSION_free), or NULL. */
SSL_SESSION *cmq_tls_session_cache_lookup(cmq_tls_config_t *cfg,
                                           const unsigned char *id,
                                           unsigned int id_len);

/* Stats. */
size_t cmq_tls_session_cache_size(cmq_tls_config_t *cfg);
```
