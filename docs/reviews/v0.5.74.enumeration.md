# v0.5.74 — JWT ES256 (D3 phase 4)

## Scope
CONNECT JWT verify is HS256/`oct` only. Real IdPs mint
ES256. This increment verifies compact ES256 (P-256) and
parses JWKS `kty=EC` keys. `jwt_ec_pub` is 128 hex (X||Y).

Remote JWKS fetch, RSA, and nkey seed/base32 stay deferred.

## Design (performance-first, safety, reliability)

- No EC key: existing HMAC / nkey paths unchanged.
- ES256 only when `alg` is ES256. HS256 tokens stay on HMAC.
- JWS signature is raw R||S (64 bytes). Wrong size fails.
- JWKS EC: `crv` must be P-256; `x`/`y` decode to 32 bytes.
- RSA/`none` still fail closed. Verify-only (no issue).
