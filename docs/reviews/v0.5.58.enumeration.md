# v0.5.58 — KV last-value store (D4 phase 2)

## Scope
D4 phase 1 persisted stream cursors. JetStream-style KV is
still missing: a last-value-per-key map, delete as tombstone.

This increment adds `cmq_kv`: fixed slots in memory, optional
filestore persist using the existing `CMQK` envelope (v0.5.53).
Object store and a partition model stay deferred.

## Design (performance-first, safety, reliability)

- Default create: no I/O. Get is a locked table probe + memcpy.
- `put` last-wins. `del` drops the key (tombstone on persist).
- Persist is opt-in (`set_persist`). Replay live WAL last-wins.
- Do not enable rotate on the KV prefix (load is live seqs).
- Keys: `[A-Za-z0-9._-]`, max 256. Value cap 1024.
- 256 slots. Table full rejects a new key (`-2`).
