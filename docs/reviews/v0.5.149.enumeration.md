# v0.5.149 — attach blocklist on reload

## Scope
Create loads `blocklist_file` into `blocklist_h`. Reload
swapped only when that handle already existed, so SIGHUP
could not enable a blocklist when create had none.

## Design (performance-first, safety, reliability)

- `cmq_blocklist_reload_attach`: empty path keeps off.
  `..` / `\` / missing file fail closed.
- Creates only when `*bl` is NULL. Existing list is left
  alone (no remount). Live swap of a present handle is
  unchanged.
- Server wraps a new list in `cmq_rch_new` like create.
