# v0.5.109 — `persist_dir` config-file key (F5 follow-up)

## Scope
`cmq_config_t.persist_dir` was only settable from C. The
config parser ignored `persist_dir=…`, so a conf-only
operator could not enable the WAL, `$JS` persist, KV,
objects, or the txn log.

## Design (performance-first, safety, reliability)

- Parse `persist_dir` with the same `cfg_set_str` path as
  `log_file`. Empty value means disabled (NULL).
- Reject `\`, controls, and `.` / `..` path components
  (same rules as filestore `dir_safe`, cap 511).
- `cmq_config_free` owns the string. `cmq_server_create`
  `strdup`s it so destroy cannot free a caller literal.
