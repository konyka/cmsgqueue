# v0.5.43 — MQTT 5.0 properties

## Goal

Parse MQTT 5 property lists without allocating, and compute the
PUBLISH payload offset from the spec layout. 3.1.1 sessions must
not interpret payload bytes as properties.

## Performance

- 3.1.1 PUBLISH: one extra `if (session_v5)` (false). No scan.
- 5.0 PUBLISH: one linear pass over the property region (already
  on the packet; no extra copy).
- Hot cmq binary path unchanged.

## Security

- Fail-closed on unknown / truncated properties (CWE-130).
- No heap; packet size already capped at 64 KiB.

## Stop

- New unit tests green.
- Header no longer says STUB/ENOSYS.
- Push `v0.5.43` to `origin`.
