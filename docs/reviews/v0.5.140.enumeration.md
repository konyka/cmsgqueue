# v0.5.140 — bind h2_port on reload

## Scope
Create binds `h2_port` via `cmq_h2_listen`. Reload ignored
the port, so SIGHUP could not enable HTTP/2 when create
had none.

## Design (performance-first, safety, reliability)

- `cmq_h2_reload_listen`: 0 / omitted keeps.
  Out-of-range fails closed.
- Binds loopback only when `*lfd < 0`. An existing
  listener is left alone (accept-fd rebind stays
  create-time).
