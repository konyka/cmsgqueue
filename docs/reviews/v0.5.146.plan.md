# v0.5.146 — bind extra listeners on reload

## Goal

SIGHUP binds extra listener slots when create left them
empty. Live accept fds are not rebound.

## Performance

One `bind`/`listen` per empty slot. Existing fd is one
compare.

## Security

Non-IPv4 and out-of-range port fail closed. Empty/omitted
cannot close a working listener.
