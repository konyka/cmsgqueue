# v0.5.107 — `$JS` default partitions

## Goal

New `$JS` streams inherit a configured default partition
count so the server can apply hash partitions without a
prior `.parts` file or a C-API call.

## Performance

`n=1` (default): one extra integer compare on first
create. No file I/O. Existing streams are unchanged.

## Security

`js_partitions` is 0–16. Names stay `[A-Za-z0-9_-]`.
A present `.parts` file is not overwritten by the default.
