# v0.5.120 — reload JWKS cache from jwks_json

## Scope
CONNECT verifies `kid` against `srv->jwks` (the ping-pong
cache built at create from `jwks_json`). `cmq_server_reload`
loaded `jwks_json` into a throwaway `fresh` and freed it,
so key-set rotation required a process restart.

## Design (performance-first, safety, reliability)

- `cmq_jwks_cache_reload` parses a non-empty document and
  `cache_put`s it onto the live slot (or creates a cache
  when create had none).
- Empty or omitted JSON keeps the current cache.
- Bad JSON fails closed; the previous slot stays.
- The live `config.jwks_json` string is replaced so
  `auth_configured` sees the new document.
- `jwks_url` refresh stays create-time (sidecar already
  re-GETs; reload does not open a network path).
