# v0.5.169 — attach TLS session cache on reload

## Scope
v0.5.23 shipped the resumption cache and wired
`new_cb` / `get_cb` on `SSL_CTX`. Create never called
`cmq_tls_session_cache_init`, so insert always missed
and reconnects paid a full handshake.

## Design (performance-first, safety, reliability)

- `cmq_tls_session_cache_reload_attach`: existing cache
  is left alone (no remount). Creates when cfg has none.
- `cmq_tls_session_cache_init` is idempotent.
- `cmq_tls_load` attaches after a successful CTX build
  (create / reload-attach new slots). Init miss is not
  fatal on load (TLS still works).
- `cmq_server_reload` attaches every live slot after
  TLS attach. Create miss fail-closes the apply.
- `cmq_tls_config_destroy` frees the cache.
