# v0.5.68 — malformed protocol version defensive test

## Scope

Defensive test: a ClientHello with version 0x03 0xFF (an
impossible future TLS version) must be rejected. OpenSSL
returns `SSL_ERROR_PROTOCOL_VERSION` from `SSL_do_handshake`,
which `cmq_tls_handshake` surfaces as -1, triggering
`client_teardown`.

## Test: `tls_e2e_handshake.malformed_protocol_version`

1. Spin up a TLS-enabled `cmq_server`.
2. Send a ClientHello with version 0x03 0xFF (5 bytes:
   `0x16 0x03 0xFF 0x00 0x01`).
3. Wait for server cleanup.
4. `cmq_server_stop` + `pthread_join` complete in bounded
   time.

## What v0.5.68 ships

Just the test. No production change.
