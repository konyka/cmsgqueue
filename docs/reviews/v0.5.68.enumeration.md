# v0.5.68 — Object-store PUBLISH path (D4 phase 5)

## Scope
`cmq_obj` is a library. PUBLISH still ignores `$OBJ.*`.
This increment applies `$OBJ.<name>` on the server path
when `persist_dir` is set (objects are files).

REQUEST-get stays deferred.

## Design (performance-first, safety, reliability)

- No store: `$OBJ.` is a normal subject.
- With store: put on non-empty payload, delete on empty.
- Name alphabet matches `cmq_obj` (no `/` `..`).
- Fanout still runs. Non-`$` subjects unchanged.
