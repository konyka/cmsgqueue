# v0.5.116 — reload log_level and acl_deny

## Scope
`cmq_server_reload` is documented to update log levels and
similar dynamic fields. Create installs `acl_deny`. Reload
only rebuilt ACL when `acl_allow` was set, never called
`cmq_log_set_level`, and ignored deny-only files.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_dynamic` applies `log_level` 0–5 and
  rebuilds the ACL when allow or deny is present.
- Default-deny `_probe_` mismatch keeps the old ACL.
- A server that started without ACL can gain one on reload.
