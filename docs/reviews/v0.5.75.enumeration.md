# v0.5.75 — nkey seed / base32 (D3 phase 5)

## Scope
`nkey_pub` is 64 hex chars only. NATS nkeys are base32
`U…` publics and `SU…` seeds. This increment decodes those
and accepts a `U…` public in `nkey_pub`. CONNECT password
stays 128 hex over `CMQNK1|<user>`.

Remote JWKS fetch and RSA stay deferred.

## Design (performance-first, safety, reliability)

- Hex `nkey_pub` path is unchanged (64 chars).
- Base32 is RFC 4648 A–Z2–7, no pad. CRC-16/XMODEM LE.
- User public prefix is `20<<3`. Seed is `S`+role, user only.
- Seed decode never stores the seed on the server; it only
  derives the 32-byte public for verify helpers.
- Bad CRC / wrong prefix fail closed.
