# v0.5.167 — attach idempo window on reload

## Scope
Create calls `cmq_idempo_create` always. Reload never
retried, so a NULL window skipped the CMQI check and
retries fan out again.

## Design (performance-first, safety, reliability)

- `cmq_idempo_reload_attach`: existing window is left
  alone (no remount). Creates when `*t` is NULL.
- Create miss fail-closes.
