# v0.5.94 — Stream REQUEST-get (D4 follow-up)

## Scope
PUBLISH writes `$JS.<name>`. REQUEST still fans out to
subscribers. This increment answers REQUEST from the
stream (last message, or empty miss).

## Design (performance-first, safety, reliability)

- Non-`$` REQUEST: unchanged.
- `$JS.` parse, then last-seq get. Miss is an empty body.
- Reply is a MESSAGE to `reply-to` on the same client
  (same hook as `$KV` / `$OBJ`). Inbox pending dropped.
- No reply-to: fail closed.
- Oversized last message: empty miss (fail closed).
