## P1 — Multi-listener runtime accept loop (real)

- **gap** → `src/server/cmq_server.c:7027` (cmq_server_run binds
  only `listen_fds[0]`; test_server now uses 28801-28803 so the
  18800-18999 range is free for multi-listener bind).
- **impact**: cannot serve two distinct certs/ports from one process.
- **effort**: M.
- **v0.5.18 approach**: re-implement the multi-bind loop with the
  port-guard. test_server is already at 28801-28803 (v0.5.14 fix)
  so 18800-18999 is free for multi-listener bind. The
  multi-thread accept (v0.5.17) is in place to dispatch the
  second fd.
