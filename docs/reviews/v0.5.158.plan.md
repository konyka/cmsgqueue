# v0.5.158 — attach object store on reload

## Goal

SIGHUP opens `{persist_dir}/obj` when create left obj
NULL. Empty / omitted keeps off. An existing handle
is not remounted. `..` / `\` fail closed.

## Performance

Existing handle: one pointer check, no mkdir.
First attach: one mkdir + calloc.

## Security

`..` / `\` / controls fail closed. Create miss does
not rewrite live `persist_dir`.
