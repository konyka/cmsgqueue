# v0.5.56 — Durable consumer cursors

## Goal

A stream consumer's ack watermark survives process restart
when a cursor directory is configured.

## Performance

Append / read: no extra loads when `cursor_path` is empty
(default). Persist is ack-path I/O only.

## Security

Path traversal rejected. Rename is atomic so a crash cannot
mix two cursor files.

## Stop

- Unit tests green (new + existing stream tests).
- Push `v0.5.56` to `origin`.
