# v0.5.73 — HTTP/2 dedicated listener (D2 phase 5)

## Scope
The frame machine and HPACK table are live, but nothing
accepts a socket. This increment binds a loopback listener
and runs one prior-knowledge h2 session: preface, SETTINGS,
then POST `:path` plus DATA.

ALPN `h2` stays unset. The server still does not call
`cmq_tls_set_alpn`.

## Design (performance-first, safety, reliability)

- Bind is loopback-only. Port 0 is allowed.
- Session I/O is poll + 200 ms. 16 KiB recv cap. No extra heap
  beyond `cmq_h2_create`.
- `:path` must be `/subject`. Reject `..`, `/`, wildcards.
- Protocol errors write GOAWAY and fail closed.
- SETTINGS ACK is written after the client's first SETTINGS.
