# v0.5.164 — attach KV manager on reload

## Goal

SIGHUP creates the KV bucket manager when create left
`kvb` NULL. An existing manager is not remounted.
Persist attach stays empty / omitted / fail-closed.

## Performance

Existing manager: one pointer check, no alloc.
First attach: one `calloc` plus mutex init.

## Security

NULL `**b` fail-closes. Does not remount a live WAL
or rewrite `persist_dir`.
