# v0.5.159 — attach txn log on reload

## Scope
Create calls `cmq_txn_set_log` when `persist_dir` is
set. v0.5.144 only did that inside the filestore-attach
block, so a live filestore whose txn log was still
unset never got `{persist_dir}/cmq.txn`.

## Design (performance-first, safety, reliability)

- `cmq_txn_reload_attach_log`: empty/omitted keeps off.
  An existing `log_path` is left alone (no remount).
- `..` / `\` fail closed. Uses live `persist_dir`
  (WAL dir). Does not remount the filestore.
