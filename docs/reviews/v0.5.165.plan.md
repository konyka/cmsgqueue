# v0.5.165 — attach $JS manager on reload

## Goal

SIGHUP creates the `$JS` manager when create left
`js` NULL. An existing manager is not remounted.
Persist attach stays empty / omitted / fail-closed.

## Performance

Existing manager: one pointer check, no alloc.
First attach: one `calloc` plus mutex init.

## Security

NULL `**j` fail-closes. Does not remount a live
last/msgs dir or rewrite `persist_dir`.
