# v0.5.175 — wire INFO host from live config

## Scope
F4 INFO advertised `"host":"0.0.0.0"` even when
create bound `config.host` (default `0.0.0.0`).
Clients that reconnect from INFO would hit the
wrong address.

## Design (performance-first, safety, reliability)

- `cmq_info_host_json`: 0 / omitted / empty is
  `"0.0.0.0"` (same as create). Apply quotes a
  dotted IPv4. Non-IPv4 fail closed.
- `send_info_frame` uses the live bind host.
  Reload does not rewrite `host` (rebind stays
  create-time), so INFO matches the accept fd.
- Quote / backslash stay rejected by the existing
  JSON helper.
