# v0.5.152 — apply config_file on reload

## Scope
SIGHUP reloads `srv->config.config_file`. Load auto-sets
that field from the path when the key is omitted. A file
that names `config_file=/other` updated `fresh` only, so
the next SIGHUP still opened the old path.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_config_file`: empty/omitted keeps the
  current path. Same string is a no-op.
- `..` / `\` / controls / len ≥ 512 fail closed (same
  rules as `persist_dir`).
- Applied last so a failed reload does not retarget.
- String apply only; no remount of a listen or WAL fd.
