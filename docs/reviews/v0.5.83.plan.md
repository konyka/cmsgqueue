# v0.5.83 — TLS-wrapped h2 I/O

## Goal

When a TLS config is present, the h2 accept path
handshakes and then reads/writes h2 frames through
`cmq_tls_read` / `cmq_tls_write`.

## Performance

Handshake and TLS I/O run only on accept. PUBLISH is
unchanged. Plaintext path keeps a single pointer check.

## Security

Self-signed loopback tests use IP SAN. Failed handshake
does not parse preface bytes as h2. Caps unchanged.

## Stop

- Unit tests green (new + existing h2 listener).
- Push `v0.5.83` to `origin`.
