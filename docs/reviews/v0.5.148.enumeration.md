# v0.5.148 — attach TLS on reload

## Scope
Create allocates `tls_config_slots[0]` only when
`tls_enabled` plus cert/key are set, and slots 1–3 only
when that listener has cert/key. Reload `apply_tls`
skipped NULL slots, so SIGHUP could not enable TLS when
create had none.

## Design (performance-first, safety, reliability)

- `cmq_tls_reload_attach`: empty cert and key keep off.
  `..` / `\` / cert-without-key / insecure backend / load
  failure fail closed.
- Creates only when `*slot` is NULL. Existing SSL_CTX is
  left alone (no remount). `apply_tls` still refreshes
  live slots first.
- Slot 0 requires `tls_enabled`. Extra slots attach on
  cert+key. ALPN `h2` is set when h2 is already on.
