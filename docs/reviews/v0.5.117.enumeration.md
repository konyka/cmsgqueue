# v0.5.117 — reload TLS cert/key via cmq_tls_reload

## Scope
F12 documents `cmq_tls_reload` as the cert-rotation path.
Create loads slots from `tls_*` / `listeners[1..3]`.
`cmq_server_reload` never updated those paths or called
`cmq_tls_reload`, so on-disk cert rotation required a
process restart.

## Design (performance-first, safety, reliability)

- `cmq_reload_apply_tls` writes non-empty fresh cert/key/ca
  onto each live slot, then `cmq_tls_reload`.
- Omitted or empty paths keep the current files.
- Reload failure (bad PEM) keeps the old SSL_CTX and fails
  the server reload before ACL/log apply.
- Slot 0 uses legacy `tls_*`; slots 1–3 use `listeners[i]`.
