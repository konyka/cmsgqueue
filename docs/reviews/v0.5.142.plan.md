# v0.5.142 — attach MQTT bridge on reload

## Goal

SIGHUP starts the outbound MQTT bridge when create had
none. Existing live peer is left to endpoint reload.

## Performance

One CONNECT + CONNACK (existing 2 s dial budget) when
starting. Existing bridge is one pointer check.

## Security

Non-IPv4 and out-of-range port fail closed. Empty/omitted
cannot attach a half-built broker. Failed dial frees the
new object.
