# v0.5.59 — Object store (D4 phase 3)

## Scope
Cursors and KV are shipped. Named blobs (object store) are
still missing. This increment adds `cmq_obj`: one file per
name under an opt-in directory, tmp + fsync + rename.

A partition / bucket server path stays deferred.

## Design (performance-first, safety, reliability)

- Get/put are one file I/O. No extra copies on the CMQ
  PUBLISH path (library API only).
- Names: `[A-Za-z0-9._-]`. Reject `..` / `/` / `\`.
- Value cap 64 KiB this version (stack/heap bound).
- Overwrite is atomic rename. Delete is unlink.
- Missing name is a miss, not an empty object.
