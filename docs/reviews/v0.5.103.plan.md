# v0.5.103 — Durable `$JS` last payload

## Goal

REQUEST-get `$JS.<name>` returns the last payload after
reopen when `persist_dir` is set.

## Performance

One extra file write on `$JS` PUBLISH only. Uncompressed
non-`$JS` subjects unchanged. REQUEST-get is a cache
read after the first load.

## Security

Names stay `[A-Za-z0-9_-]`. Path is `{persist_dir}/js`
already created by cursor persist. No subject in the file
beyond the name token.
