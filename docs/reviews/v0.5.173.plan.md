# v0.5.173 — verify CHECKSUM on BATCH

## Goal

BATCH with `CMQ_FLAG_CHECKSUM` verifies and
strips the trailing CRC32C before count parse.
Omitted flag keeps the payload unchanged.

## Performance

No flag: one bitwise-AND. Flag set: one CRC32C
over the wire payload plus a 4-byte strip.

## Security

Mismatch / short / NULL fail closed before any
entry is walked. Decompress still runs first so
COMPRESSED+CHECKSUM covers plaintext.
